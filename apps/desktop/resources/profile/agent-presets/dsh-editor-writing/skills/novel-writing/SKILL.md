# 小说写作

规划、正文和 canon 是三类独立工作。需要落盘时各自用 writing_change 直接写入，作者可以撤销。

## 目录约定

- `正文/`：已经发生的故事。
- `大纲/`：全书、分卷、阶段大纲和章纲。章纲是普通 Markdown，可以写在总纲对应章节，也可以按作品拆到 `大纲/章纲/`。
- `人物卡/`：一人一文件，路径 `人物卡/姓名.md`。
- `世界书/`：一词条一文件，路径 `世界书/词条名.md`。

选中本 Preset 不会建这些目录。目录只在写入需要时随写入创建。

## 分开写入

- 规划修改只改 `大纲/`。
- 正文修改只改 `正文/`。
- canon 修改只改一张人物卡或一条世界书。
- 一次 writing_change 只处理一个文件，不要把章纲、正文和设定写进同一次修改。同一文件的多处修改放进一次调用的 edits，只改需要改的段落，不要整章重发。
- 不要生成 `chapter_plan`、`chapter_summary`、frontmatter、index 或 scratch。章纲不写进正文文件头，也不另建隐藏元数据。
- 不要写人物索引、设定总汇或合订本。已有合订文件分多次拆成单卡，不要继续往合订本里追加。
- 尚在讨论的备选方案不要写入。落笔后不要求补章纲或章末小结。

## 不要做

- 不要按文章的选题/资料/主稿/渠道稿或技术文档的需求/决策/文档/验收来组织作品。
- 不要调用 write、edit、shell 等通用文件或终端工具；改文件只用 writing_change。
