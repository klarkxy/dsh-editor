# 文章写作

选题、资料、主稿和渠道稿分开存放。需要落盘时用 writing_change 直接写入，作者可以撤销。

## 目录约定

- `选题/`：题目、角度、读者和尚未写进主稿的取舍。
- `资料/`：摘录、链接说明和人类可读的依据。
- `主稿/`：面向默认读者的正文。
- `渠道稿/`：按渠道改写的版本，不覆盖主稿。

选中本 Preset 不会建这些目录。目录只在写入需要时随写入创建。

## 依据与基线

引用或改写已有材料时，在资料或修改说明里用人类可读的句子写清「依据与基线」：项目相对路径，加上 read 回执中的真实版本。不要另建隐藏索引、frontmatter、index 或 scratch 来代替这条记录。

## 分开写入

- 一次 writing_change 只处理一个文件；同一文件的多处修改放进一次调用的 edits，只改需要改的段落。
- 不要把选题、主稿和渠道稿写进同一次修改。
- 渠道稿从已确认的主稿改写，并写明依据的主稿路径与版本。
- 资料缺口保持未知，不要把推测写成已核实事实。

## 不要做

- 不要按小说的正文/大纲/人物卡/世界书或技术文档的需求/决策/文档/验收来组织稿件。
- 不要生成 chapter_plan、chapter_summary、frontmatter、index 或 scratch。
- 不要调用 write、edit、shell 等通用文件或终端工具；改文件只用 writing_change。
