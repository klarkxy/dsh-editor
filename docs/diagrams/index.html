DSH Editor 0.2.0 · 架构图

规范源文件在仓库 docs/diagrams/；推送 main 后由 GitHub Pages 发布。

四张图是同一套系统的不同切面。Host 插件住在 DSH 进程里，不是旁边的独立服务；host-api 是进程内库导入。Electron 只启动 DSH 并打开 loopback URL，不直接加载 shell。

桌面运行时

两道进程：Electron 启动唯一 DSH 子进程；shell / manuscript / workbench / kernel 都在 Host 内。

插件分级与依赖

三个公开 tarball 与桌面 profile。桌面保留校对引擎但暂停校对界面，知乎配置位于设置中。

组合边界

普通业务、可选智能增强、独立公开插件三个视角。独立 Web 校对和资料 RPC 可以不经过 Agent；桌面入口按 0.2.0 整理。
