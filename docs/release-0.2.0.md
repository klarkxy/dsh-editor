# 0.2.0 本地验收记录

日期：2026-09-12。产品源码基线为 `3e874cf1551f1a5511d924f28e24421a98668a42`，桌面版本 `0.2.0`、Node `24.16.0`、DSH `0.1.5-rc.2`。这是更新发布文档前的本地回执，最终标签构建和下载产物另行验证。

## 已完成

- 全 workspace 构建、类型检查通过；994 项单元测试通过。
- 六组界面 / 联调共 79 个检查组通过：设置与文件栏、正文菜单、智能体写作、资料面板、full 组合与禁用入口。

- Windows 安装版和便携版生成后，包内 Node / DSH / profile 文件数、字节数和 SHA-256 与运行时清单一致。
- 实际启动最终便携 EXE，完成新建作品、新建文档、正文落盘、知乎设置打开和桌面校对入口缺席检查；正常退出码为 0，应用端口与调试端口均释放。

[结构化回执与本地产物哈希](verification/release-0.2.0-local.json) 仅保存必要的版本、计数、校验值和结果，不包含临时作品路径或请求凭据。详细本地截图保存在开发工作区的 `e2e/out/` 与 `.pack/portable-e2e/`。

## 发布前的后续检查

文档先合入主分支，再以相同版本号创建标签与 draft Release。Windows / macOS 标签任务成功后，下载附件、核对 `sha256sums.txt`，再启动下载后的 Windows 便携包执行保存和退出验证，完成后才公开 Release。

本地旧包、日期不同的在线记录和静态源码复查都不能代替这些检查。macOS 的安装包由 CI 构建并做包结构校验，本机没有 macOS 交互验证；本轮也不对供应商生成质量、计费或持续运行作结论。
