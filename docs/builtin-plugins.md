# 内置插件与设置

Editor 自有功能统一列在「插件 → 已安装与市场 → 内置插件」。插件列表管理功能是否启用；「设置」管理 Editor 的模型、写作、快捷键与用量。启停其他插件不会接管或移除内置模型设置。

## 内置功能清单

| 功能 | 加载与开关 |
| --- | --- |
| 稿纸、写作界面、工作台、写作偏好、开发者偏好、插件管理 | 必需基础模块，随应用加载，不可关闭；查找、保存、导出等操作由这些模块承载，不另造空开关。 |
| 模型配置 | 必需模块；复用随包提供的模型中心服务，在 Editor 设置中管理供应商、四个模型档位、对话／补全／改写和运行上限。 |
| 写作辅助 | 补全与选段改写共用一个真实开关；生成候选仍需作者接受才改变正文。 |
| 文稿校对、文档概览 | 可分别开关。校对底层组件由校对功能管理，不提供独立全局开关。 |
| 人物与世界书、写作记忆 | 随包提供，默认关闭，可按需启用。作品、卡片与历史记录不会因停用被删除。 |
| 快捷键、资料预览、MCP 资源 | 随发行组合提供的官方功能也列入内置插件。 |
| 语音输入 | 随发行组合提供，默认关闭；在「插件」页开启后，对话输入区才出现麦克风。语音模型仍需用户主动准备，不在启动时自动下载。 |
| 通用写作、小说创作、文章与自媒体、技术文档 | 复用原写作模式开关。通用写作不可关闭；其他模式的开关影响新对话，不改变已有对话。 |
| 会话写作工具、小说工具 | 由会话所选模式挂载，显示“由会话控制”；不能在全局列表中强行启停。 |

共享界面座位和工作区辅助库只是实现依赖，不伪装成可开关的功能。

## 模型设置归属

「设置 → 模型」始终提供供应商、快速／对话／思考／幻想档位、对话／补全／改写模型和运行上限。所有修改沿用现有中央策略与版本冲突检查，不复制另一份配置。

「插件」页的“插件模型”只显示插件注册的其他用途；内置对话、补全、改写不会在两处重复编辑。未单独绑定的档位保留原有跟随规则。写作与辅助请求分别限制并发；写作只尝试一次，辅助重试上限不控制写作。

模型中心的既有服务成为 Editor 必需的“模型配置”载体。升级会清理应用管理的旧“模型中心关闭”开关，以保证四档模型可实际生效；中央策略、其他插件开关、写作模式与安装记录保留。手动维护的非应用管理补丁不会被覆盖。

## 预装与市场插件

内置归属来自应用生成的发行清单，不由包名或外部插件自报决定。其他随包提供的公共插件归入“预装插件”；市场安装的包归入“已安装插件”。预装来源和可关闭性是两个独立属性：必需的共享服务仍不可关闭，普通预装功能保留开关。

插件停用时由原生加载器卸载能力；保存成功、实时生效和需要重启分别显示。停用不删除稿件或既有配置，重新启用仍使用原数据。检查或安装第三方插件仍沿用原有流程。
