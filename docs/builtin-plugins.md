# 内置插件与设置

Editor 自有功能由官方插件管理器列出；「设置」管理 Editor 的模型、写作、快捷键与用量。启停其他插件不会接管或移除内置模型设置。写作搭档只有一个标准 preset，随桌面 profile 部署，没有模式开关。

## 内置功能清单

| 功能 | 加载与开关 |
| --- | --- |
| 稿纸、写作界面、工作台、写作偏好、搭档对话设置、插件管理 | 必需基础模块，随应用加载，不可关闭；查找、保存、导出等操作由这些模块承载，不另造空开关。 |
| 模型配置 | 必需的内置设置；使用 DSH 原生供应商和写作偏好，分别管理新对话、补全、改写模型，不依赖公共模型中心服务。 |
| 补全服务 | 必需内置服务，随应用加载，不可在插件页停用或卸载；行内补全的触发方式（关闭 / 手动 / 自动）在「设置 → 写作」管理，生成候选仍需作者接受才改变正文。 |
| 文档概览、人物卡与世界书、记忆维护 | 必需内置功能，随桌面发行组合默认启用，不可在插件页关闭或卸载；人物卡和世界书直接在文件树中编辑。 |
| MCP 资源 | 随发行组合提供的官方功能入口列入内置插件；默认关闭，配置 MCP 服务后按需启用。快捷键、资料预览是发行版常驻的运行时基础组件，不作为插件列出（作者此前通过旧卡片关掉的仍会列出，便于重新打开）。 |
| 语音输入 | 随发行组合启用，对话输入区提供麦克风入口。模型未准备时，点击麦克风打开准备引导；下载和准备由用户主动开始，启动或查看准备页不会自动下载模型、启动识别进程或请求麦克风。可在「插件」页关闭。 |
| 会话写作工具、小说工具 | 由标准写作搭档 preset 挂载，显示“由会话控制”；不能在全局列表中强行启停。 |

共享界面座位和工作区辅助库只是实现依赖，不伪装成可开关的功能。

## 模型设置归属

「设置 → 模型」始终提供供应商和新对话／补全／改写模型。模型选择保存到现有写作偏好，使用原生设置的版本冲突检查；不再使用退役的共享模型策略。

公共插件的模型选择在各自配置页管理，内置对话、补全、改写不会重复出现。未指定模型时，新对话跟随原生默认模型，补全和改写先跟随当前会话。写作仍有固定的取消、超时和输出长度边界，只尝试一次。

升级会将旧模型策略中的写作选择迁入原生设置，并清理应用管理的退役插件开关和安装记录，修改前保存配置备份。其他插件开关、历史策略和作者记录保留；旧版写作模式的开关记录读取时忽略；手动维护的非应用管理补丁不会被覆盖。

## 预装与市场插件

内置归属来自应用生成的发行清单，不由包名或外部插件自报决定。其他随包提供的公共插件归入「DSH-Editor 内置插件」；市场安装的包归入「用户插件」。官方插件区列两类条目：Editor 能用上的官方组合包（目前只有语音输入），以及官方功能暴露的配置卡（目前是「网页搜索与获取」与「Agent 循环」）。其余官方包不显示，但作者已启用、或已安装且可卸载的仍列出，便于关闭或卸载。「发现」页推荐网络搜索管理器与知乎，按需安装；网页搜索由 DSH 原生搜索工具承担。普通预装功能保留开关，共享库不提供空开关。退役的 AI Services、Model Center、Memory、Self-improvement 与 Fusion 不再显示；其历史数据不删除。

插件停用时由原生加载器卸载能力；保存成功、实时生效和需要重启分别显示。停用不删除稿件或既有配置，重新启用仍使用原数据。安装、卸载、脚本批准、安装详情与插件启停都经官方插件管理器服务执行；插件页的三类目录负责清单展示与启停入口，启停调用同一服务。

## 插件页的三类清单

插件页的「已安装」按来源分三类展示：

- **DSH 官方插件**：Editor 能用上的上游官方组合包（当前只有语音输入）与官方功能配置卡（网页搜索与获取、Agent 循环）；作者已启用、或已安装且可卸载的其他官方包也显示在此，便于关闭或卸载。
- **DSH-Editor 内置插件**：应用发行清单登记的内置功能，不含第三方公共插件。
- **用户插件**：作者自行安装的组合包；默认发行组合下该类为空。
