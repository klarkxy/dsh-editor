# 使用指南

## 安装与更新

从 [GitHub Releases](https://github.com/klarkxy/dsh-editor/releases) 下载。Windows 可运行便携版 EXE 或安装器；macOS 将 dmg / zip 中的应用拖入「应用程序」。便携版首次启动需要准备本地环境，可能稍慢。

应用未签名，Windows 可能提示未知发布者，macOS 首次可在访达中右键选择「打开」。只运行可信来源的文件。

更新前保存作品，在「设置 → 关于」检查和下载更新：

| 平台 | 下载完成后 |
| --- | --- |
| Windows 安装版 | 点「退出并安装」 |
| Windows 便携版 | 点「重启并替换」 |
| macOS | 打开下载文件夹，退出应用，用新版替换旧版 |

下载会核对发布页的 SHA-256；失败时可前往发布页手动下载。保留旧版安装包，以便关闭新版后回滚。

0.4.x 系列更新包含 DSH 运行时升级。更新前请备份作品文件夹和应用数据目录：Windows 为 `%USERPROFILE%\.dsh-editor`，macOS 为 `~/.dsh-editor`；若设置了 `DSH_HOME`，备份该目录。回退旧版时，先退出应用，再恢复更新前的应用数据备份；仅保留旧安装包不能还原已迁移的配置与会话。

## 打开作品

首页上方是「继续写作」，显示最近的作品和上次写到的章节，点它直接回到稿纸；下方目录式列表列出其余最近作品。「新建」按作品名在「文档/dsh-editor」下建立文件夹；「打开作品」直接打开已有文件夹。同名目录不会被覆盖。

新作品从空白开始。在稿纸上点「写第一篇」，后续用文件栏「新建文档」继续。新建文件夹在「目录操作」或文件树右键菜单中。也可以先与搭档讨论人物、设定和大纲，让它按讨论结果直接写入后再改。目录按需创建，已有 Markdown / TXT 可直接使用。

顶部作品名菜单可切换最近作品、打开或新建作品、导出与返回首页。从最近列表移除入口不会删除作品。

## 写作与保存

中间是稿纸；左侧栏用「文件 / 搜索」页签切换文件树与跨文件搜索；右侧辅助栏用「搭档 / 资料 / 工具」页签切换——搭档是对话，资料是预览与钉住对照，工具是记忆等面板。文件树不显示 `.md` / `.txt` 扩展名，章节按中文数字的自然顺序排列（第十章在第九章之后）。顶栏可收起两侧栏或进入专注模式；宽屏下拖动分隔线调整栏宽；窗口变窄时侧栏先让位为抽屉，作者手动开合的选择优先。右键文件选「钉在旁边」可打开一份只读对照。

正文自动保存，`Ctrl+S` 可立即保存。切章或离开作品前会先保存；遇到失败、冲突或尚未保存的新输入时，先处理当前文档再继续。

文件被其他程序改过时，可重新载入磁盘版本，或先另存冲突副本。临时草稿可帮助恢复意外退出前的内容，但不能代替备份。

正文右键和标题栏「⋯」提供编辑、查找、补全与改写操作。「设置 → 写作」调整字体、字号、行距、纸宽、首行缩进、分节符居中、打字机滚动和段落聚焦。设置与插件在同一个全页视图，左侧导航分「写作、模型、助手、外观、快捷键、插件、用量、关于、高级」。

稿纸菜单中的「选中当前段落」复用聚焦段落的空行分隔规则，仅改变可见稿纸中的选区，不改变文件内容，也不会选中隐藏的文件头。选中后可继续使用现有的复制或改写操作。它不是 Markdown 语法树选块，也不会给段落生成持久化 ID。

## 与搭档协作

在「设置 → 模型 → 供应商」连接模型，再分别设置新对话和正文补全的模型。未单独指定时，新对话使用 DSH 默认模型，补全跟随当前会话模型，再回退到 DSH 默认模型。选区改写直接使用当前搭档对话及其模型。插件自身的模型选择位于各插件配置页。默认对话模型只影响新对话；模型失效或保存失败会显示错误。

添加接口只需三个信息：API 地址、API 密钥（可留空）和 API 协议（多数服务选 OpenAI 兼容）。地址没带 `http(s)://` 时会自动补上：本机回环地址（如 `127.0.0.1:3425/v1`、`localhost:11434`、`[::1]:3425/v1`）默认补 `http://`，局域网与公网地址默认补 `https://`（需要明文时可显式填写 `http://`）；结尾多贴的调用路径（如 `/chat/completions`）会自动剥掉。不需要密钥的服务（比如本机网关）密钥可以留空。点「连接」后接口会自动列出可用模型，勾选要用的再点「保存」即可；每个模型的参数（上下文、最大输出、输入类型、思考强度）自动从接口应答和 models.dev 公开目录补齐，不用手填。连接失败或接口不返回列表时可以「手动填写模型名称」，多个名称用逗号或空格分隔。发行版内置的供应商仍走「从内置列表添加」，选中后按表单填密钥即可。

供应商列表中的「DeepSeek Account」行改用 DeepSeek 账号登录：点「登录」会在系统浏览器中打开授权页，完成后其模型无需 API 密钥即可使用；「退出登录」不影响已保存的 API 密钥。

每个模型的高级区里有上下文窗口、最大输出、输入类型和思考强度四个参数。输入类型用「文本」「图片」两个复选框表示，至少保留一种；思考强度可选关闭、标准六档，手写的自定义档位只读显示。填写这些参数可以靠自动补全：点「获取可用模型」采纳端点列出的候选时，候选自带的参数直接写入；手动输入模型 ID 后失焦，或点行内的「从目录补全」，会向 models.dev 查询这个模型的公开参数（上下文、最大输出、输入类型、推理档位）并补齐仍空着的字段。补全只填空字段，不覆盖你已填的值；所有改动都在草稿里，要点「保存」才生效。models.dev 查询是按需发起的单次公开数据 GET，结果在本机缓存 24 小时；断网时会沿用旧缓存（提示「使用缓存数据」）或提示手动填写。内置供应商的模型继承已安装的模型目录，参数留空即跟随目录，不触发查询。

- **补全**：光标处选择「光标处补全」或按 `Ctrl+Enter` 手动补全，`Tab` 接受、`Esc` 放弃；可停止生成或比较候选。「停顿后提示」在写作设置中开启，仅用于正文，且只在光标位于文末时自动提示。
- **改写**：选中文字，在选区下方的浮层里填写要求（可选预设标签），提交后作为当前搭档对话的新消息发送。对话返回后搭档直接改稿，改过的段落在稿纸上标出，可在对话记录中定位、撤销。
- **直接修改**：正文与大纲的修改或新建由搭档按你的要求直接写入；对话里留一条记录，可「定位」「撤销」「查看改动」。同一份文件的多处修改一次写入；原文找不到、不唯一，或目标文件有你未保存的修改时会拒绝写入（「作者正在编辑，稍后再试」），保存或让搭档重读后再改。
- **规划**：大纲与章纲同样由搭档直接写入；人物卡与世界书是普通 Markdown，由搭档在协作中自动维护、写入即生效，历史可在记忆面板查看并撤销。没有强制的章节收尾步骤。

每部作品只有一个搭档，没有会话列表、新建对话或模式选择。打开空作品时，搭档先问你想写什么；打开已有内容的作品时，搭档第一次接入会先读一遍目录、大纲、人物卡、世界书与最近几章的开头，再说说它对作品的认识。小说、文章与技术文档的写法由搭档按作品内容选用。`Enter` 发送，`Shift+Enter` 换行。

对话变长、换模型、离开超过缓存有效期，或作者约定与审查豁免改变时，应用会在两轮之间整理对话：写一份交接后接着聊，界面上留一条「对话已整理」标记，更早的内容仍按顺序显示在上方，可点「显示更早的对话」展开。整理时输入框上方显示「正在优化对话…」；有待回答的问题时会推迟整理。离开电脑达到「闲置回顾时间」后，搭档会整理一次进展，回来时在对话末尾显示「离开期间的整理」。需要以前聊过的细节时，搭档会自己检索之前的对话原文。

「设置 → 助手」中的作者约定适用于所有作品，需要点击「保存作者约定」后生效；未保存草稿在当前工作台中关闭、重开设置后仍保留；退出应用前仍需保存。本书独有的规则放在作品的 `AGENTS.md`、人物卡或世界书，由搭档在协作中自动维护，历史可在记忆面板查看并撤销；辅助规则文件在作者文件树中隐藏，可用外部编辑器维护。为了让模型缓存持续命中，`AGENTS.md` 与作者侧写在一段对话内保持不变，修改从下一次整理对话后进入搭档的固定上下文；搭档需要最新内容时会直接读文件。作者约定保存后，下一次发送前会先整理对话。

「设置 → 助手 → 对话整理」调整两个时间：「闲置回顾时间」默认 15 分钟，表示离开电脑多久后整理一次进展；「缓存有效期」默认 1 小时，可设为永不失效，超过这个时间没有对话，下次发送前会先整理对话。闲置回顾时间须短于缓存有效期。写作中长考常超过 5 分钟，Editor 写入的模型供应商默认使用长缓存（Anthropic 协议为 1 小时档，写入单价高于 5 分钟档，读取仍便宜）；你在供应商配置里显式设置的缓存档位会保留，DeepSeek 自动缓存不受影响。


## 管理作品

| 操作 | 入口与注意事项 |
| --- | --- |
| 查找替换 | 当前稿纸用 `Ctrl+F` / `Ctrl+H`；跨文件用 `Ctrl+Shift+F`。「全部替换」先预览再确认，已变化的文件会跳过，可重新搜索处理。 |
| 移动与重命名 | 文件树右键菜单；也可拖到目标目录。移动、重命名遇到同名会取消，复制会自动改名。 |
| 拆章与合章 | 正文 Markdown 的右键菜单。拆章锚点须唯一；合章会移出被并入的章节。两者先预览提案，再确认应用。 |
| 保存与回滚版本 | 文件栏「目录操作 → 保存版本 / 历史版本」。自动保存只更新文稿，不自动创建历史版本。历史页先显示文稿改动，辅助文件与版本编号可展开「版本详情」查看。回滚前自动保存当前状态；快照只覆盖 Markdown / TXT，不包括图片和隐藏文件。 |
| 导出 | 作品菜单「导出稿件」。先按目录分组列出文档清单（默认只勾「正文」，没有该目录时全勾），勾选要导出的文档后选择 Markdown / TXT / DOCX / EPUB。 |
| 删除 | 文件树右键「删除」；永久删除，除非此前已保存到历史版本，否则无法恢复。没有文档归档入口。 |

备份或迁移作品时复制整个文件夹，包括隐藏的 `.dsh-editor/`。不要把正文只放在这个元数据目录中。

## 官方 DSH 功能

Editor 保留稿纸和写作搭档界面，通过 DSH 的公有布局合同与界面槽位加载官方插件。官方定时任务不在此发行组合中。

| 功能 | 使用方式 |
| --- | --- |
| 资料预览 | 在文件树点图片、PDF、`.doc` / `.docx`、`.ppt` / `.pptx`、`.xls` / `.xlsx`、`.csv` / `.tsv` 文件，在资料栏查看；Markdown / TXT 仍在稿纸中打开。 |
| MCP 资源 | 默认关闭；在「插件」页启用「MCP 资源」，资源来自已经配置的 MCP 服务。 |
| 语音输入 | 随包启用，对话输入区提供麦克风入口。首次点击会打开准备引导，也可从「插件」页进入语音准备页；由你选择「下载并准备」。启动和查看准备页只检查本地资源，不自动下载模型、启动识别进程或请求麦克风。准备完成后，点击麦克风开始录音，把转写放入当前对话草稿；可在「插件」页关闭语音输入。下载大小和首次运行时间取决于模型与环境。 |
| 快捷键 | 「设置 → 快捷键」使用官方搜索、录制和重置界面；桌面版保存自定义按键，重启后继续使用。 |

## 辅助功能与设置

设置全页视图的「插件」分区常驻「已安装」与「发现」。「已安装」按来源分三类展示：DSH 官方插件（Editor 能用上的官方组合包——目前只有语音输入——和官方功能的配置卡，目前是「网页搜索与获取」与「Agent 循环」；作者已启用、或已安装且可卸载的其他官方包也显示，便于关闭或卸载）、DSH-Editor 内置插件和用户插件；运行时与开发者组件收在「高级组件」。点击任意插件行打开其详情页：配置项、组件清单、包信息、版本豁免与卸载都在详情页完成。顶栏「添加插件」打开安装对话框：输入包名检查后即可安装，进度、构建脚本批准与失败原因都在对话框内呈现；安装中标题栏显示「安装进行中…」。必需模块只读。

发现：进入页面先列「推荐插件」（当前为网络搜索管理器与知乎），下方是被移除、可重新添加的随附插件（「可重新添加的随附插件」），两组都为空时才显示搜索提示。输入关键词、npm 包名或 GitHub 仓库即可搜索；结果显示官方管理器的安装与启用状态，未安装项点击「安装」把所选规格填入编辑器「添加插件」对话框，核对后再确认；已安装项可直接打开详情页配置。复制规格保留在「高级」中。未写版本的本机包名优先匹配本地绝对 `link:` 规格；写明 npm 版本或 GitHub 规格则走 pluginManager 服务安装。作者移除的可选包升级后保持移除，自选版本予以保留；移除后的随包来源仍可搜到并再次添加。网页搜索由 DSH 原生搜索工具承担，走官方 DeepSeek 搜索后端，不再预装第三方搜索插件；其他搜索后端可安装推荐的网络搜索管理器。

发现搜索见[插件适配](../packages/dsh-editor-plugins/README.md)。

以下是 Windows 桌面版默认按键；macOS 请以「设置 → 快捷键」中的显示为准。可在该页搜索、录制或重置工作区与窗口命令，自定义结果保存在桌面应用数据中；下表的编辑命令需先聚焦稿纸。Web 的部分默认组合键不同，例如段落聚焦为 `Ctrl+Shift+P`。

## 按词审稿与按需查资料

对话写入记录的「查看改动」会把差异分别标出删除和新增的词语，中文按词比较，并保留原来的空白、标点和换行。超长或差异过多的文本会降级为较粗的对照，不影响稿纸输入。差异结果仅用于展示，写入早已落盘。

在稿纸选中一个名称，通过右键或顶栏更多菜单选择「查相关资料」，按需查询当前文件列表中的 `人物卡/` 与 `世界书/`。文件名和文件正文都可命中，同名但不同路径的资料分别显示。结果可「打开资料」或「钉在旁边」；打开时沿用既有的保存与版本检查，钉住时沿用只读资料栏。查询不需要开启目录快捷入口，不自动建立索引、创建卡片、修改资料或注入模型上下文。搜索失败、跳过或截断会明确提示。

## 遇到问题

模型无法连接时，检查接口地址、密钥、额度和网络；搭档的失败提示会说明原因（如密钥无效、额度用尽、连不上服务或找不到模型），可按提示到「设置 → 模型」核对。搭档写入被拒绝（原文找不到、不唯一，或你正在编辑目标文件）时，先保存或让搭档重读最新文件后再改；稿纸提示磁盘冲突时先保留副本再重新载入。启动异常时保留诊断信息并联系开发者。
