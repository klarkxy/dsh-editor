# DSH Editor 使用者指南

## 从一个本地作品开始

DSH Editor 是免安装的 Windows x64 小说写作应用。双击便携版 EXE 后，可以选择“新建”或“打开作品”。作品始终保存在你选择的本地文件夹中。

“新建”会建立 `正文`、`大纲`、`人物卡`、`世界书` 和首章模板。“打开作品”不会补目录或模板；它会直接显示原有文件树，并让 DSH Agent 阅读现有文本、建立 `.dsh-editor/作品索引.md`。索引失败时可在左侧重试或重建。

“打开作品”和“新建”都会先展开同一个文件夹路径框；你可以直接输入路径，也可以使用“选择文件夹”调用系统目录选择器。已有 Markdown 作品直接使用“打开作品”，不会再经过另一套复制式导入入口。

作品打开后，顶部“作品”返回最近列表；存在未保存内容时会先阻止返回。作品选择器旁的“···”可以修改应用内显示名，不会移动或重命名磁盘文件夹。首页“最近”列表的“···”还可以把入口从列表移除；确认页会再次说明，作品文件、正文、对话和日志都不会删除，以后仍可用“打开作品”重新加入。

主界面默认分为文件树与稿纸两栏。顶部“搭档”或右下角入口会打开第三栏，便于边写边讨论；再次点击会收起。底层运行组件不需要单独启动或配置。

### 调整工作台布局

顶部“文件”可以折叠或恢复左侧资料栏，“搭档”控制右侧助手栏。两条竖向分隔线可以拖动调整栏宽；聚焦分隔线后也可用左右方向键微调，双击恢复默认宽度。文件栏是否展开及两侧栏宽度会保存在本机界面偏好中。

点击“专注”会暂时隐藏文件栏、搭档栏和调宽线，只保留居中的稿纸；点击“退出专注”后恢复进入前的两侧栏状态，不会关闭对话或丢失未保存内容。

### 常用快捷键

工作台右上角“?”会列出全部快捷键，也可以按 `Ctrl+K` 后再按 `Ctrl+S` 打开。高频操作包括 `Ctrl+B` 文件栏、`Ctrl+J` 搭档栏、`Ctrl+\` 专注写作、`Ctrl+L` 聚焦搭档输入框、`Alt+[` / `Alt+]` 切换章节，以及 `Ctrl+,` 打开接口设置。快捷键弹窗支持 `Esc` 关闭并锁定焦点，不会把按键传给正文。

## 配置接口

第一次启动若没有检测到可用 Key，应用会先打开独立设置页，配置成功前不会进入作品区。之后可随时从右上角“设置”返回该页面。目前只提供：

- DeepSeek：填写 API Key；
- 自定义兼容接口：填写接口地址和 API Key；连接时只读取可用模型列表，不发送补全探测。

点击“连接”。成功后界面只显示“连接成功”，不会回显 Key 或模型原始响应。已经配置的 Key 可以留空继续使用。Key 只交给 DSH 的私有凭据存储，界面不会读取其明文。设置页只负责接口连通，不会改变正在进行的对话。

连接完成后，设置页还可以选择补全方式。默认“仅手动”，只有点击稿纸下方“补全”时才请求；改为“停顿后提示”后，仅在 `正文` 章节中连续输入并停顿约 1.5 秒时生成一次建议。自动提示不会用于大纲、人物卡或世界书，也不会直接写入，仍需点击“接受补全”或按 `Tab`。

“跨作品作者约定”用于维护不属于某一本书的稳定偏好，例如叙事人称、行文禁忌或协作习惯。最多 1,200 字，只保存在本机应用界面存储中，不会写进作品目录；所有作品的搭档、行内补全和选段修改都会参考。它不是本书设定，也不会改变文件权限或代替你本轮提出的要求。某一本书独有的规则仍应写入该作品的“项目总览”、人物卡或世界书。

## 写作与保存

左侧可以新建章节、大纲、人物和世界设定。所有新建操作都在应用内填写名称，不会再弹出系统输入框。需要整理长篇时，从“新建资料 → 卷/部”在 `正文` 下建立一级目录；把鼠标移到该卷/部，点击右侧“＋”即可把新章节直接建在其中。卷内章节仍参与全文搜索、前后章导航和整书导出。创建卷/部不会移动现有章节，也不会建立第二份目录数据库。

正文编辑后约 800 毫秒自动保存，也可以按 `Ctrl+S` 或点击“保存”。

顶部可在“稿纸 / 概览 / 卡片”之间切换。“概览”显示章节数、总字数、草稿/修订中/已定稿分布、最近编辑章节和扫描警告；“卡片”把同一批章节按三种状态分列，并可切到“大纲”页签。章节标题栏、概览行和章节卡片都可以修改状态。旧作品无需迁移，未设置的章节默认是草稿；第一次改为“修订中”或“已定稿”时，作品内才会创建 `.dsh-editor/chapter-status.json`。文件损坏时状态修改会停用并提示，但正文编辑和原有导出仍可继续。

如果文件同时被其他程序修改，DSH Editor 不会静默覆盖。你可以重新载入磁盘版本，或先保存带时间戳的冲突副本再重新载入；放弃本地草稿前会在工作台内再次确认，取消后草稿原样保留。

临时草稿会帮助恢复意外退出前的内容，但草稿不是备份；重要作品仍应定期复制或纳入版本管理。

### 补全与选段修改

把光标放在正文中并点击“补全”，应用会在当前光标处生成一段建议；建议只显示在稿纸上，不会自动写入。点击“接受补全”或按 `Tab` 才会加入草稿，点击“放弃”或按 `Esc` 则保持正文不变。生成较慢时可以点击“停止补全”。不满意时可点“再来一个”，最多保留三条并用“上一条 / 下一条”比较；新请求失败或返回重复内容时，已有候选不会丢失。

如果在设置里开启“停顿后提示”，只有当前稿纸仍聚焦、光标没有选中文字、光标前已有足够正文且本次编辑尚未提示过时才会请求。继续输入、切换文档、出现版本冲突或已有建议时都会取消旧计时；失败不会在没有新输入时循环重试。

选中文字后点击“修改选段”，稿纸会并排显示原文与修改后内容。点击“应用修改”或按 `Ctrl+Enter` 才会替换原选区；点击“放弃”不会修改正文。生成期间继续输入或切换文档会立即停止旧请求，避免把过期结果写进新内容。

### 查找、导航与文件整理

左侧搜索可以查整部作品或只查 `正文`，结果会显示文件、行号和片段。点击结果会打开文档并选中命中文字；如果搜索后文件已变化，只打开文档而不强制定位。搜索有文件数、总大小和结果数量上限，达到上限或跳过内容时会明确提示。

打开人物卡或世界书后，可以点击稿纸下方“查找正文引用”。应用优先搜索当前选中文字，否则使用文档第一个标题，再退回文件名，并自动把范围限制到正文。`人物索引`、`设定总汇`等通用文档不会用泛化标题搜索，而会把焦点放到搜索框，请你输入具体名称。当前稿件未保存时仍能查看结果，但必须先保存才能跳转。

稿纸顶部的左右箭头按完整 `正文` 目录自然排序切换章节，即使文件夹尚未在树中展开也不会漏章。存在未保存内容或版本冲突时，搜索跳转和章节切换会暂停，避免丢失当前编辑。

Markdown/TXT 文件右侧的“···”可以重命名或归档；`正文` 中的章节还可以移动到其他卷/部，或移回正文根目录。移动会先显示完整目标路径，保留原文件名和类型，不覆盖同名文件；源文件在磁盘上变化、目标目录不安全或目标已占用时会停止。移动后的章节会立即按新路径参与前后章导航、搜索和整书导出。重命名只修改同一文件夹中的名称并保留扩展名，不覆盖已有文件。归档不是永久删除：文档会从文件树移到作品内的安全归档区，可从“已归档”恢复到原路径；原路径已被占用、内容已变化或记录损坏时会停止且不覆盖。归档操作不提供硬删除。

### 整部作品快照

顶部“快照”会保存当前磁盘上的 Markdown/TXT 文本和章节状态文件，不包含尚未保存的编辑内容，也不会带入其他隐藏元数据。恢复必须选择新的空文件夹，并始终生成一个新作品副本，不会原地覆盖当前作品。恢复中断后可继续，或在文件仍与恢复清单一致时显式清理；任何作者改动都会阻止自动清理。旧快照没有状态文件时，恢复后的章节全部按草稿显示。

## 使用写作助手

右侧可以自由讨论剧情、人物、设定和文字。每次发送时，应用会按固定顺序带上有界的项目总览、总纲、人物索引、设定总汇和（如已存在）作品索引；单份最多 4,000 字符、合计最多 12,000 字符。除此之外，应用会用本次请求、当前文档路径和当前文档已保存内容匹配 `世界书` 内的设定；按优先级带入匹配项，单份最多 3,000 字符、合计最多 6,000 字符，不会挤占固定资料。

通过“新建资料 → 设定”创建的文件会自动带有触发配置。打开普通世界书时，稿纸上方会显示“触发设置”，可以按一行一个填写触发词，并设置启用状态和 `-100..100` 的优先级；点击“应用设置”后进入同一份编辑草稿，并沿用自动保存和版本冲突保护。旧式无配置文件会先用文件名作为触发词，第一次应用时生成规范文件头。显式文件头损坏时表单会停用，避免覆盖未知字段或注释，需要先在正文中手工修复。

配置仍保存在 Markdown 文件开头，便于在其他编辑器中查看或手工编辑：

```yaml
---
triggers: [港口, 海关]
enabled: true
priority: 8
---
```

`triggers` 支持行内列表或逐行列表，按字面包含匹配；`priority` 越高越先纳入。没有配置的旧世界书仍会用文件名作为触发词。显式配置损坏、停用、超出扫描限制或读取失败的文件不会进入提示。消息下方的“项目上下文”可展开查看固定资料、触发世界书、匹配来源、截断情况和扫描计数，但不会展示资料原文。固定资料缺失或单个世界书读取失败不会阻止发送；如果整个上下文编译失败，消息不会送出，输入内容会保留供重试。写作助手仍可在当前作品中进一步查找并阅读 Markdown 资料。

讨论、构思、写作、审读可以在同一段对话里自然切换，不需要选择工作模式。写作助手会在有帮助时静默参考内置的小说创作经验；这些参考不会覆盖你的正文、设定或当次要求。

如果已经填写跨作品作者约定，每条消息的“项目上下文”摘要会显示本次带入的约定字符数，但不会在对话气泡中重复展示约定原文。约定与本轮请求、项目资料在结构上分开；历史对话仍能按原格式读取。

写作助手不能直接改稿。它提出文件修改时，界面会显示原文与修改后内容，或新文件内容。只有点击“应用”后才会写入；点击“忽略”不会产生任何修改。如果文件已经变化，旧建议会失效，避免覆盖新内容。

搭档栏顶部可以切换当前作品已有的对话，也可以用铅笔按钮在应用内修改对话名称。存在尚未发送的输入时，切换对话、新建对话、返回作品列表或打开设置前都会在工作台内确认；取消后输入和当前对话原样保留。不同对话的草稿和发送状态不会混在一起。没有手工命名的新对话会在第一条助手回复出现后生成简短名称，手工名称始终优先。当前版本不提供对话归档或删除入口，以免产生无法从界面恢复的隐藏对话。

点击“新对话”后先选择本次使用的模型，再开始一段新的讨论。当前对话顶部也会显示它正在使用的模型。输入消息时按 `Enter` 发送，按 `Shift+Enter` 换行；中文输入法还在组合文字时不会误发送。底层工具名称、调用参数和原始错误不会显示在产品界面中。

## 导出

顶部可导出 Markdown 或 TXT。应用递归收集 `正文` 中的 Markdown/TXT 章节，按与章节导航一致的自然顺序合并：

- Markdown 保留标题与格式；
- TXT 去掉 Markdown 标题标记和分隔线，保留纯文字内容。

选择格式后会先显示导出预检：文件名、章节自然顺序、总字数和空章。空章只警告，仍可继续；正文为空时不会生成空导出物。存在未保存内容或版本冲突时必须先保存。确认后直接下载预检中已经读取的同一份内容，不会再次读取磁盘；取消不会生成文件。

## 更新与回滚

更新前先保存作品并关闭旧版本。保留旧 EXE 和它的 SHA-256 作为回滚点；如需回滚，关闭新版后重新运行旧 EXE。当前版本没有自动更新和代码签名，Windows SmartScreen 可能显示未知发布者，请只运行可信来源的文件。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无法连接模型 | 检查接口地址、Key、额度和网络，再重新连接。 |
| 保存冲突 | 重新载入磁盘版本，或先另存冲突副本。 |
| 建议无法应用 | 文件已经变化；让写作助手根据最新内容重新提出建议。 |
| 无法恢复归档 | 原路径已有文件、归档内容已变化或记录损坏；应用不会覆盖现有内容。 |
| 搜索结果没有定位 | 搜索后文件版本已变化；应用只打开文档，请重新搜索。 |
| 导出为空 | 先确认 `正文` 目录中存在 Markdown 或 TXT 章节。 |
| SmartScreen 警告 | 当前便携版未签名；核对可信来源和 SHA-256。 |
| 启动后不是写作界面 | 保存截图和诊断信息并联系开发者。 |
