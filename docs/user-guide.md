# DSH Editor 使用者指南

本文以桌面 **0.2.0** 为基础。从 0.1.x 升级时，文稿校对改走侧栏与 `Ctrl+Shift+L`，知乎资料移入设置，辅助文件从作者文件栏和全文搜索中隐藏。

## 作品与首页

DSH Editor 提供 Windows 便携版 / 安装版和 macOS（Apple Silicon）版的写作应用。Windows 可直接双击便携版 EXE，或运行安装器（`Setup.exe`）装到开始菜单；macOS 打开 dmg（或解压 zip）后把应用拖进「应用程序」。首次启动后，可以选择「新建」或「打开作品」。新建作品默认保存在「文档/dsh-editor」下的同名文件夹中；已有作品仍从你选择的本地文件夹打开。

「新建」会要求填写作品名称，然后在「文档/dsh-editor」下建立该文件夹。新作品一开始是空白稿纸，只写入作者看不到的 `AGENTS.md`（给写作搭档用的作品规则），不会预建 `正文`、`大纲`、`人物卡`、`世界书` 目录，也不会预写总览、总纲或首章。同名文件夹已存在时会提示，不会覆盖。资料和章节由你在左侧新建，或由写作搭档按这部作品的需要提出提案。「打开作品」不会补资料目录或模板；已有 Markdown / TXT 会按原样打开。新作品可以先在搭档栏讨论并采用人物卡、世界书和章纲，再进入第一篇；进入作品时不会自动请求模型。

「打开作品」会直接打开系统目录选择器，选中文件夹后立即进入作品。目录选择器不可用时，可以在路径框里直接输入路径。打开空文件夹时仍可选择「在这里新建」。已有 Markdown / TXT 的文件夹直接用「打开作品」，不必再复制进新目录。

作品打开后，顶部的作品名菜单可切换最近作品，并提供打开作品、新建、导出稿件与返回作品列表。当前开发版本会先保存正文，再切章、跳转搜索结果、切换或离开作品；新建章节和导出也会先保存。

保存失败、存在冲突或保存期间仍在输入时，会留在原处保留内容。首页「最近」列表可以把入口从列表移除；确认页会再次说明，作品文件、正文、对话和日志都不会删除，以后仍可用「打开作品」重新加入。

## 界面布局

主界面默认是三栏：左侧文件栏、中间稿纸、右侧写作搭档。文件栏列出已有的作品文件；`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`COPILOT.md` 等辅助文件不在文件栏和作者全文搜索中显示，也不会进入搜索替换范围；文件本身和智能体的读取能力保留。

新作品的文件栏一开始是空的；正文、大纲、人物卡和世界书等目录会在你或写作搭档真正创建文件时出现。文件栏提供搜索和版本操作；稿纸标题栏保留文档名、章节导航、字数、保存状态和「⋯」。

左侧是一棵普通目录树：文件夹在前、按名称排序，点击行首箭头展开或收起。新建通过右键菜单进行：在任意文件或文件夹行上右键，选择「新建文件 / 新建文件夹」，文件行建在其所在目录、文件夹行建在其内部；在树的空白区域右键则建在根目录。悬停文件夹行尾出现的 `＋` / `▣` 是同样的行内快捷入口。文件名不带扩展名时按 `.md` 创建。所有新建操作都在应用内填写名称，不会再弹出系统输入框。

### 调整工作台布局

顶栏用图标切换左侧文件栏、专注模式和右侧搭档栏（悬停可见说明）。窗口较窄时，点「搭档」会从右侧以抽屉打开，点旁边变暗的稿纸即可收起，不会再占一列把稿纸挤没。再窄到大约手机宽度时，只保留稿纸，文件栏和搭档栏都收起。宽屏下两条竖向分隔线可以拖动调整栏宽；聚焦分隔线后也可用左右方向键微调，双击恢复默认宽度。文件栏是否展开及两侧栏宽度会保存在本机界面偏好中。

点击顶栏专注图标会暂时隐藏文件栏、搭档栏、作品概览和调宽线，只保留居中的稿纸；再点一次后恢复进入前的两侧栏状态，不会关闭对话或丢失未保存内容。`Ctrl+\` 同样进入或退出专注写作。

### 钉住对照

写某一章时常要盯着一张人物卡、一条设定或大纲。在文件树里右键任意 Markdown / TXT 选「钉在旁边」，或用命令面板「钉住当前文件」，稿纸右侧会多出一栏只读对照，位于稿纸和搭档栏之间，有自己的调宽线（260–560px）。人物卡和世界书按字段列出，章节和其他文本去掉文件头后原样显示；对照栏顶部可以取消钉住或在稿纸里打开该文件。

一次只钉一份，再钉别的会替换；文件被改动后对照栏自动刷新，文件被删除则自动取消。专注模式会一并隐藏对照栏，退出后恢复。钉住的路径和栏宽保存在本机界面偏好中，作品里找不到该文件时会静默取消。

顶栏可在浅色 / 深色主题之间切换；选择会写入 `localStorage["dsh-editor.theme"]`（值为 `light` / `dark`），并与设置里的外观同步。首次进入还会参考系统 `prefers-color-scheme`。

### 常用快捷键

下列键位按 Windows 标示，macOS 的应用命令通常使用对应的 ⌘。命令面板同时显示当前平台的快捷键；调用编辑命令前需聚焦稿纸。

- `Ctrl+S` 保存当前章节
- `Ctrl+B` 折叠 / 恢复左侧文件栏
- `Ctrl+J` 折叠 / 恢复右侧写作搭档
- `Ctrl+L` 聚焦右侧对话输入框
- `Ctrl+\` 进入或退出专注写作
- `Ctrl+K` 打开或关闭命令面板
- `Ctrl+,` 打开设置
- `Alt+[` / `Alt+]` 上一章 / 下一章
- `Ctrl+F` 稿纸内查找
- `Ctrl+H` 稿纸内查找并替换
- `Ctrl+Shift+F` 打开跨文件全文搜索
- `Ctrl+Shift+O` 打开作品概览
- `Ctrl+Shift+L` 校对当前文档
- `Ctrl+Shift+C` 在文件树中展开人物卡
- `Ctrl+Shift+W` 在文件树中展开世界书
- `Ctrl+Alt+T` 开关打字机滚动（输入或移动光标时保持当前行居中）
- `Ctrl+Alt+P` 开关段落聚焦（淡化光标所在段落以外的正文）
- `Tab` 采纳当前补全建议
- `Esc` 关闭查找栏，或放弃补全 / 改写建议
- `Ctrl+Enter` 应用稿纸上的选段修改提案

命令面板（`Ctrl+K`）还可以新建 / 打开作品、导出稿件、跳转到文档、校对当前文档 / 全部文档、打开记忆维护、切换主题和打开设置。

## 写作

空作品的中央稿纸提供「写第一篇」和一句引导；已有文稿但未打开文档时可选择「新建文档」。也可以悬停或右键文件夹，在该目录中创建文件。

正文编辑后约 800 毫秒自动保存，也可以按 `Ctrl+S` 或从正文右键 /「⋯」菜单选择「保存」。

如果文件同时被其他程序修改，DSH Editor 不会静默覆盖。你可以重新载入磁盘版本，或先保存带时间戳的冲突副本再重新载入；放弃本地草稿前会在工作台内再次确认，取消后草稿原样保留。保存冲突期间不能用 `Ctrl+S` 绕过。

临时草稿会帮助恢复意外退出前的内容，但草稿不是备份；重要作品仍应定期复制或纳入版本管理。多窗口同时打开同一作品时，草稿按窗口隔离；编辑器底部可以列出并采纳其他窗口留下的备份。

### 查找与替换

当前稿纸内可用 `Ctrl+F` 查找、`Ctrl+H` 查找并替换。跨文件的全文搜索与「全部替换」见下文「作品管理」。

### 正文操作菜单

正文右键与稿纸标题栏「⋯」提供同一组操作：撤销、重做、剪切、复制、粘贴、全选、保存、当前文档查找与替换、光标处补全和选段改写。生成停止、候选、改写预览、冲突和备份恢复在需要时出现；打字机与段落聚焦在设置 → 写作中调整。

右键落在选区内会保留选区，落在外面则移动光标；「⋯」、`Shift+F10` 和菜单键使用当前选区。方向键可导航，`Esc` 关闭并返回编辑器；查找框和弹窗打开后接管焦点。中文组字期间不会打开菜单。

剪切会先确认复制成功再删除，失败时保留正文并提示；粘贴仅插入纯文本，可单独撤销。等待剪贴板期间编辑正文、切章或重新载入，会取消过期操作。空剪贴板不会删除选区。没有选区时不能剪切、复制或改写；选中文字时不能补全。加载期间不能编辑；生成期间不能再次启动补全或改写，继续编辑会取消旧生成；出现冲突时禁止保存和生成，仍可整理或复制本地草稿。关闭写作辅助后不会发送生成请求。

### 稿纸、排版与打字机

设置 → 写作 →「稿纸与排版」可即时调整打字机滚动、段落聚焦、字号（14–28px）、行距、段距、衬线 / 无衬线 / 等宽字体，以及窄栏（60ch）/ 中栏（76ch）/ 通栏。改动立刻作用到稿纸，并保存在本机 DSH 设置。命令面板也提供打字机与聚焦的快捷开关；`Ctrl+Alt+T` / `Ctrl+Alt+P` 同样生效。

### 专注模式

顶栏专注图标或 `Ctrl+\` 只留居中稿纸，仍可看到字数与保存状态；见上文「调整工作台布局」。

### 章节切换

稿纸顶部的 `‹ ›` 按完整 `正文` 目录自然排序切换章节，即使文件夹尚未在树中展开也不会漏章。也可以用 `Alt+[` / `Alt+]`。存在未保存内容或版本冲突时，章节切换会暂停，避免丢失当前编辑。

### 前置规划：人物卡、世界书与章纲

正文页只负责落笔。开始写一章前，先在搭档中讨论人物、世界设定和情节安排，再让搭档分别提出人物卡、世界书与大纲提案；作者预览、调整并明确采用后，才进入正文。

- **人物卡**：一人一份，保存在 `人物卡/`。
- **世界书**：地点、势力、物品、规则、历史等一词条一份，保存在 `世界书/`。
- **大纲与章纲**：都是计划，统一保存在 `大纲/` 下的普通 Markdown。章纲可以写在总纲对应章节，也可以按作品需要拆到 `大纲/章纲/`；不写入正文章节的隐藏文件头。

落笔前的初始人物卡、世界书和大纲/章纲都先显示提案，采用后才落盘；需要的新目录会随采用安全创建。尚未讨论清楚的备选方案只留在对话中，不会自动变成作品设定。后续协作里修订既有内容或含义有歧义时仍需作者确认，这不是每章结束后的整理步骤。hidden legacy 会话才有自动追加人物 / 世界资料的维护工具；四个新 Preset 没有它。

推荐顺序是：讨论方向 → 设计人物卡与世界书 → 设计并采用大纲/章纲 → 落笔正文。写完以后，编辑器不会再要求作者「整理本章」、补章纲或填写章末小结；若作者主动要复盘或调整，仍可在对话中讨论并修改对应的规划文件。

旧作品正文中已有的 `beats` / `state` 文件头不会被自动删除或覆盖，但写作页不再提供编辑入口，新工作流也不会继续生成这些字段。

### 补全与选段修改

把光标放在正文中，在右键或「⋯」菜单选择「光标处补全」，应用会在当前光标处生成一段建议；建议只显示在稿纸上，不会自动写入。点击「接受补全」或按 `Tab` 才会加入草稿，点击「放弃」或按 `Esc` 则保持正文不变。生成较慢时可以点击「停止补全」。不满意时可点「再来一个」，最多保留三条并用「上一条 / 下一条」比较；新请求失败或返回重复内容时，已有候选不会丢失。

如果在设置里开启「停顿后提示」，只有当前稿纸仍聚焦、光标没有选中文字、光标前已有足够正文且本次编辑尚未提示过时才会请求。继续输入、切换文档、出现版本冲突或已有建议时都会取消旧计时；失败不会在没有新输入时循环重试。自动提示只用于 `正文` 章节，不会用于大纲、人物卡或世界书。

选中文字后，在右键或「⋯」菜单选择「选段改写」，直接输入这次的修改要求。生成后会显示原文与修改后内容，点击「应用修改」才替换原选区；点击「放弃」保留原文。应用可以单独撤销。生成期间继续输入或切换文档会停止旧请求，避免把过期结果写入新内容。

改写要求在独立弹窗的多行输入框中填写，最多 400 字；弹窗同时显示原选区摘要，普通回车换行，Ctrl/Cmd+Enter 提交。提交前若正文已经变化，本次操作会取消。没有选中文字时，选段改写不可用。

普通长回复不会被自动截断；思考强度显示在模型旁边，档位为 none / low / medium / high / xhigh / max。搭档栏宽度用左侧分隔线拖动调整。

### 提案确认

写作助手不能直接改稿。它提出文件修改时，界面会显示原文与修改后内容，或新文件内容。只有点击「应用」后才会写入；点击「忽略」不会产生任何修改。如果文件已经变化，旧建议会失效，避免覆盖新内容。

### 对话管理

搭档栏顶部可以切换当前作品已有的对话。⋯ 菜单可以重命名、归档或恢复当前对话。归档后对话离开主切换列表，出现在「已归档对话」可展开列表里，随时可以恢复。只剩一段对话时不能归档，需要先新建另一段。

存在尚未发送的输入时，切换对话、新建对话、归档或返回作品列表前都会在工作台内确认；取消后输入和当前对话原样保留。打开设置是覆盖层，不会丢弃输入。不同对话的草稿和发送状态不会混在一起。

没有手工命名的新对话会在第一条助手回复出现后生成简短名称；手工名称写在本作品的对话记录里，始终优先显示，不会被自动名称覆盖。

点击「新对话」会先选择对话模式（通用写作、小说创作、文章与自媒体、技术文档），确认后再开始一段新的讨论，并使用设置里的默认对话模型；若未设置默认，则使用模型列表中的第一项。「小说创作」只多只读知识卡（`novel_knowledge`），正文变更仍走与其它新 Preset 相同的确认提案；不会自动采访、建索引、写 frontmatter 或编译旧信封。输入框下方显示当前对话模式与模型；模式在创建时选定、现有对话不会改模式，模型可随时更换；展开模型列表时可查看提供方。四个写作模式只能查找、阅读作品资料，或通过提案请你预览修改，不能使用终端。开发者模式下可选的官方 Agent 模式使用其自身完整工具（含终端）。输入消息时按 `Enter` 发送，按 `Shift+Enter` 换行；中文输入法还在组合文字时不会误发送。主要界面使用简短的操作状态；需要排查问题时可展开错误详情。

## 资料

人物卡和世界书就是作品目录里的 Markdown。`人物卡/`、`世界书/` 在实际创建后出现在文件树里；点开文件即可在稿纸里阅读和编辑。`Ctrl+Shift+C` / `Ctrl+Shift+W` 或命令面板会展开对应目录。一人一文件，一词条一文件。请搭档整理时也不要写 `人物卡/人物索引.md` 或 `世界书/设定总汇.md` 这类合订本；地点、势力、物品、规则、历史各占一条世界书。

稿纸会隐藏已闭合的文件头，只显示正文。需要对照字段时，把文件钉在稿纸旁边。文件头里的结构化字段可由搭档整理，或用外部文本编辑器维护。要在正文里找某张卡的名字、别名或触发词，用跨文件搜索。

人物卡常用字段：

```yaml
---
name: 林见
aliases: [巡卫林]
role: 主角
gender: 男
age: 十七
faction: 北城巡卫
tags: [刀客]
status: 在场
relations:
  - to: 阿秀
    kind: 旧识
summary: 北城巡卫，守港夜班。
---
```

世界书文件头支持分类、标签和摘要；也可保留旧版或手工维护的其它字段：

```yaml
---
triggers: [港口, 海关]
enabled: true
priority: 8
category: 地点
tags: [水路]
summary: 入港盘查与夜禁。
---
```

`category` 可选地点 / 势力 / 物品 / 规则 / 历史 / 其他，也可以自己写。未在稿纸中展示的文件头字段可用外部文本编辑器维护；`triggers`、`enabled`、`priority` 不再控制对话的自动注入。树里新建、重命名或删除后，文件树会跟着更新。

## 作品管理

### 作品概览与写作曲线

命令面板「作品概览」或 `Ctrl+Shift+O` 会用作品概览替换中间稿纸（稿纸仍挂在后台，未保存草稿不会丢掉）。概览顶部是章节数与总字数；下面按自然顺序列出各章标题、字数和修改时间。

点标题打开该章；空章会标出。

「字数分布」按章画一条简单柱状图。「写作曲线」显示近 30 日每日增量（今日加亮）和近 12 周合计，并列出最近编辑的章节。成功保存正文后约 5 秒会静默记下当天总字数，供曲线使用，不会挡住保存。

### 全文搜索

跨文件全文搜索走侧栏「搜索」、命令面板「全文搜索」或 `Ctrl+Shift+F`：可在整个作品或仅正文中查找字面量，结果按文件分组并显示摘录。点击一处会打开该文件并选中匹配范围；当前文档有未保存内容时会先阻止跳转。

搜索框下方的「替换为」配合「全部替换…」可以把所有命中一次改掉，典型用途是给人物或地名改名。点击后面板内先列出涉及的文件数、命中数和每个文件的命中数，确认后才逐个文件写入。写入前会核对文件版本和命中位置是否仍与搜索时一致；期间被改过的文件会跳过并在结果里标出，可点「重新搜索」再处理。

替换的是搜索返回的精确位置，不区分大小写这一点与搜索一致。当前文档在替换范围内且有未保存内容时，整个操作会先被阻止；替换完成后当前稿纸自动重新载入。

### 校对

四个 Preset 共用中性文稿校对（`dsh-editor-proofread-panel`；canonical `desktop` 组合安装）。侧栏打开「校对」，或用 `Ctrl+Shift+L` / 命令面板「校对当前文档」扫当前稿纸；「校对全部文档」扫全部可见 Markdown / TXT。检查类型为标点、错别字、敏感词、重复与口癖，不含人物卡对照。追加与忽略名单仍写在作品目录 `.dsh-editor/敏感词.txt`、`敏感词-忽略.txt`。

### 打开已有文稿

已有 Markdown / TXT 的文件夹用首页或作品菜单的「打开作品」即可。打开时如果发现未完成的旧导入记录，可以继续复制或安全清理：只会删除导入清单中记录且内容未变化的文件，不会删除目标文件夹或其他文件。

### 导出

作品菜单或命令面板的「导出稿件」，会先预检可见 Markdown / TXT：按自然章节顺序列出空文档警告和总字数，再把同一份整理结果下载为合并后的 Markdown、TXT、DOCX 或 EPUB。

预检对话框里可以选择格式；DOCX / EPUB 会在本机打包后下载为「作品名.docx」或「作品名.epub」。当前文档有未保存内容时会先要求保存。合并在本机完成，不会改作品目录里的文件。

### 删除

右键「删除」会先在确认框说明不可撤销（除非之前已提交到历史），确认后删除该文件或整个文件夹。当前版本没有面向作者的文档归档入口。

### 保存版本与回滚

从文件栏的版本操作中选择「保存版本」，会把当前作品存为一次快照，提交说明自动使用当前时间（`YYYY-MM-DD HH:mm`）。点「历史版本」会在中间打开提交记录：每条都有短哈希、说明、时间和相对上一版的文件增减（新增 / 修改 / 删除）。选中一条后可以「回滚」：作品内容回到该次提交的状态，回滚前的当前状态会先自动保存为一次新提交，因此回滚本身随时可以撤销。命令面板里也能打开同一份记录。

快照只覆盖作品内的 Markdown/TXT 文本；图片等其他文件不会被快照或回滚影响。`.dsh-editor/` 下的旁路文件也不进入快照。

### 文件树操作

在文件树中右键任意文件或文件夹，会弹出操作菜单：新建文件 / 新建文件夹、复制、剪切、粘贴、重命名、删除；正文章节还多出拆章与合章。也可以把文件或文件夹拖到目标目录（或该目录里的任意一行）来移动。复制 / 剪切先把条目放进内部剪贴板，再到目标目录（或其中任意一行）的右键菜单里「粘贴」；复制的条目可以反复粘贴，剪切粘贴一次后剪贴板自动清空。

复制遇到同名会自动改名（如 `第一章 2.md`），移动和重命名遇到同名会提示并取消。当前文档有未保存内容时，剪切它所在的文件或目录会先被阻止。

### 拆章与合章

右键正文 Markdown 章节选「拆章…」，或在稿纸里把光标放到要切开的段落、用命令面板「在光标处拆章」：对话框里填锚点（从命令面板进入时预填光标所在段落）和新文件名（默认按原名加「-下」或数字加「-2」，在同一目录下取不存在的名字）。锚点必须在文件里恰好出现一次。确认后并不直接改文件，而是弹出与写作助手相同的提案卡，可以先看拆分预览，再点「应用」；应用后打开新文件。

右键选「合并到上一章」或「与下一章合并」，会把两章按自然顺序合成一章：前者把本章接到上一章末尾，后者把下一章接到本章末尾。被并入的那一章会从目录中移出。这两项同样先过提案卡确认；`.txt` 章节不能拆章，也不能与非 Markdown 的邻章合并。相关文件有未保存内容时会先被阻止。

## 设置

首次启动仍可直接进入作品区。顶栏末端的设置控件、写作搭档顶部的「设置接口」以及 `Ctrl+,` 打开的是同一个设置弹窗。

### 模型

「模型」分区管理接口、模型与凭据，首次使用引导也由 DSH 处理。密钥只交给 DSH 的私有凭据存储，界面不会读取或回显明文。

这里可以分别选择「对话模型」「补全模型」「改写模型」。补全和改写留空时跟随当前对话；对话模型只用于新开的对话，已有对话仍保留自己的选择。

### 助手

「跨作品作者约定」用于维护不属于某一本书的稳定偏好，例如叙事人称、行文禁忌或协作习惯。最多 1,200 字，保存在本机 DSH 设置中，不会写进作品目录；输入后点击「保存作者约定」。所有作品的搭档、行内补全和选段修改都会参考。

旧版浏览器偏好会在首次启动时迁移；迁移失败时原值会继续生效，并可在「助手」或「写作」分区重试。它不是本书设定，也不会改变文件权限或代替你本轮提出的要求。

### 写作

「写作」分区只保存编辑器自身的偏好。默认「仅手动」，只有从正文菜单选择「光标处补全」时才请求；改为「停顿后提示」后，仅在 `正文` 章节中连续输入并停顿约 1.5 秒时生成一次建议。自动提示不会用于大纲、人物卡或世界书，也不会直接写入，仍需点击「接受补全」或按 `Tab`。

某一本书独有的规则仍应写入作品根目录的 `AGENTS.md`、人物卡或世界书。`AGENTS.md` 可用外部文本编辑器维护，或通过搭档提出的记忆维护记录确认修改。

### 稿纸与排版

同一分区的「稿纸与排版」控制打字机、段落聚焦和字号 / 行距 / 段距 / 字体 / 纸宽，见上文「稿纸、排版与打字机」。

### 语言与外观

「通用设置」里可以改语言、外观，以及写作助手忙碌时按 Enter 的行为（排队发送或插话发送；`Ctrl+Enter` 执行另一种操作）。

「语言」可选中文或 English，切换后立即生效、不需要重启，覆盖编辑器外壳与右侧 DSH 对话区的全部界面文案。

「外观」可选浅色、深色或跟随系统，与顶栏的浅色 / 深色切换互通。跟随系统没有单独的存储值，读取时会按系统偏好落成浅色或深色。

### 插件

「插件」按作者用途组织内置功能：写作辅助、校对、作品概览、人物与世界书、写作记忆、知乎资料。每个功能只有开或关；详情可以查看组成。稿纸、写作界面与插件管理本身不能关闭。若提示未能保存，可重试；用户自己改过的受保护配置会保留。

社区插件按安装包管理，可以安装和卸载。市场页只有一个输入框：输入关键词后点击「搜索」，查找带 `dsh-plugin` 主题的 GitHub 仓库；粘贴 `owner/repo`、`github:owner/repo` 或 GitHub 仓库链接时，按钮会变为「安装」。也可以按 Enter 提交。点击「安装」会打开弹窗并自动检查；阅读结果后，点击「确认安装」才会开始安装，也可以取消。检查有注意事项时仍可确认，无法加载的插件则不能安装；检查失败可以重试。检查通过也不保证运行时一定成功。

仓库缺少编译产物时，会尝试使用同仓库、同名、同版本且完整性校验通过的 npm 发布包，并在结果中说明来源。「在 GitHub 打开」会通过系统浏览器打开对应仓库。安装后尚未加载的插件会标为「待重启」，仍可直接卸载。卸载失败会在确认弹窗内说明原因，可以重试。安装与卸载后需要重启应用；作品文件、对话和设置不会被删除。

### 用量

「用量」分区显示本机过去 30 天的模型调用统计：今日概览、近 7 日分模型柱状图，以及按时间倒序的请求日志（模型与 tokens）。超过 1000 的数字显示为 K / M / T。没有调用的日期按零显示。只统计本机用量，不含费用估算。

### 知乎资料

在设置中打开「知乎资料」，用于填写知乎开放平台 Access Secret，让搭档调用站内搜索、全网搜索、热榜、直答和公开知识库检索。桌面顶栏不再提供知乎查询按钮。设置内提供「设置 / 用量 / 知识库 / 连接测试」四个标签，凭据输入使用遮罩。也可在此查看近 30 天的知乎调用用量，以及把参考资料上传到知乎知识库。文件会保存到知乎云端，请勿上传未发表手稿。

### 关于

「关于」分区显示当前版本，并可以检查与安装更新，见下文「更新与安装」。

## 更新与安装

设置里的「关于」分区显示当前版本，并可以从 GitHub Releases 检查新版本；发现新版时会给出发布说明，可以直接在设置里「下载更新」——下载优先走 GitHub 镜像，全部失败后回退直连，下载完成会按发布页附带的 SHA-256 校验和验证文件完整性。

Windows 安装版点「退出并安装」后由安装向导覆盖安装；Windows 便携版点「重启并替换」后应用自动完成 EXE 替换并重启；macOS 没有代码签名，无法自动替换，下载后点「打开所在文件夹」，退出应用并用新版 dmg 中的应用替换「应用程序」里的旧版。下载失败时仍可用「前往下载」经浏览器手动下载。更新前先保存作品。

保留旧版本和它的 SHA-256 作为回滚点；如需回滚，关闭新版后重新运行旧版本。当前版本没有代码签名：Windows SmartScreen 可能提示未知发布者，macOS 首次打开需在访达中右键应用并选择「打开」。请只运行可信来源的文件。

## 数据存放

作品目录下的 `.dsh-editor/` 是应用私有元数据，文件树和作者搜索不显示。提交快照时，路径中任一段以 `.` 开头的项都会被排除，因此 `.dsh-editor/*` 一律不进入快照。常见内容包括：

- `作品索引.md`：仅 hidden legacy `dsh-editor` 会话在打开已有作品并跑旧采访 / 索引管线时写入；四个新 Preset 不会自动生成
- `writing-log.json`：按本机日期记录的每日字数，供写作曲线使用
- `敏感词.txt` / `敏感词-忽略.txt`：校对用的追加名单与忽略名单
- `snapshots/`：提交与回滚使用的文本快照
- `archive/`：可恢复归档
- `scratch/`：legacy 助手的临时工作草稿；knowledge-only 与其它新 Preset 不挂 scratch 工具。界面不显示，不进入对话上下文，也不进入快照

这些旁路文件缺失或损坏时，对应功能会退回默认值，不会挡住正文编辑。不要把手稿只放在 `.dsh-editor/` 里。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无法连接模型 | 检查接口地址、Key、额度和网络，再重新连接。 |
| 保存冲突 | 重新载入磁盘版本，或先另存冲突副本。 |
| 建议无法应用 | 文件已经变化；让写作助手根据最新内容重新提出建议。 |
| 想导出现稿 | 导出走作品菜单或命令面板的预检下载，可选 Markdown / TXT / DOCX / EPUB。 |
| 删了文件还能找回吗 | 右键「删除」是永久删除，当前版本没有面向作者的文档归档入口。 |
| 主题不对 | 顶栏切换浅色 / 深色，或到设置 → 通用设置改外观；选择会写入 `localStorage["dsh-editor.theme"]`，首次进入还会参考系统 `prefers-color-scheme`。 |
| 想找正文中的某段文字 | 当前章用 `Ctrl+F` / `Ctrl+H`；跨文件用 `Ctrl+Shift+F` 或侧栏「搜索」；章节仍可用 `Alt+[` / `Alt+]` 翻。 |
| 想看全书字数或作品概览 | 用 `Ctrl+Shift+O` 或命令面板中的「作品概览」。 |
| 找不到校对入口 | 侧栏打开「校对」，或 `Ctrl+Shift+L` / 命令面板「校对当前文档」；「校对全部文档」扫全部可见 Markdown / TXT。 |
| 想改人物卡或世界书 | 在文件树打开对应 Markdown；对照字段可钉在旁边。 |
| 删掉的对话还能找回吗 | 不能。删除只在本机记墓碑，DSH 没有会话删除；归档过的对话可以恢复，删除过的不能。 |
| 想把对话区也切成英文 | 「语言」选 English 后，右侧 DSH 对话区随外壳一起切换，界面文案全部有英文。 |
| SmartScreen 或 Gatekeeper 警告 | 当前版本没有代码签名；核对可信来源和 SHA-256。Windows 可能提示未知发布者，macOS 首次请在访达中右键打开。 |
| 启动后不是写作界面 | 保存截图和诊断信息并联系开发者。 |
