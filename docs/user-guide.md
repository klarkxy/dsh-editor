# DSH Editor 使用者指南

## 作品与首页

DSH Editor 提供 Windows 便携版 / 安装版和 macOS（Apple Silicon）版的小说写作应用。Windows 可直接双击便携版 EXE，或运行安装器（`Setup.exe`）装到开始菜单；macOS 打开 dmg（或解压 zip）后把应用拖进「应用程序」。首次启动后，可以选择“新建”或“打开作品”。新建作品默认保存在「文档/dsh-editor」下的同名文件夹中；已有作品仍从你选择的本地文件夹打开。

“新建”会要求填写作品名称，然后在「文档/dsh-editor」下建立该文件夹，并放入空的 `正文` 目录，不会预写总览、总纲、人物索引、设定总汇或首章。同名文件夹已存在时会提示，不会覆盖。`大纲`、`人物卡`、`世界书` 在实际创建后才会出现在文件树里；也可以从侧栏「人物 / 设定」用“新建人物卡 / 新建设定”创建。资料和章节由你在左侧新建，或由写作搭档按这部作品的需要创建。“打开作品”不会补目录或模板；它会显示原有作品文件。需要搭档了解作品时，再展开“了解这部作品（可选）”主动开始，不会在进入作品时自动请求模型。

“打开作品”会直接打开系统目录选择器，选中文件夹后立即进入作品。目录选择器不可用时，可以在路径框里直接输入路径。打开空文件夹时仍可选择“在这里新建”。要把一堆已有 Markdown / TXT 复制进新的空作品，用首页的“导入已有 Markdown / TXT”，或作品菜单、命令面板的“导入作品”。

作品打开后，顶部把当前作品名、最近作品切换与「作品」菜单放在同一组控件里。点作品名可在最近作品之间切换；「作品」菜单提供打开作品、新建、导入作品、导出 Markdown / TXT、已归档与返回作品列表。存在未保存内容时会先阻止切换或离开。首页“最近”列表仍然可以把入口从列表移除；确认页会再次说明，作品文件、正文、对话和日志都不会删除，以后仍可用“打开作品”重新加入。首页和命令面板也可以新建空作品后导入已有 Markdown / TXT。

## 界面布局

主界面默认是三栏：左侧文件栏、中间稿纸、右侧写作搭档。文件栏列出已有的作品文件；AGENTS.md 等辅助文件不在文件栏显示，文件本身和智能体的读取能力保留。新作品先有空的正文目录，进入后点击“写第一章”开始；其它资料目录在实际创建后出现。文件栏提供搜索和版本操作，资料面板也可从命令面板或快捷键打开。稿纸标题栏保留文档名、章节导航、字数、保存状态和“⋯”。

左侧是一棵普通目录树：文件夹在前、按名称排序，点击行首箭头展开或收起。新建通过右键菜单进行：在任意文件或文件夹行上右键，选择“新建文件 / 新建文件夹”，文件行建在其所在目录、文件夹行建在其内部；在树的空白区域右键则建在根目录。悬停文件夹行尾出现的 `＋` / `▣` 是同样的行内快捷入口。文件名不带扩展名时按 `.md` 创建。所有新建操作都在应用内填写名称，不会再弹出系统输入框。

### 调整工作台布局

顶部“文件”可以折叠或恢复左侧资料栏，“搭档”控制右侧助手栏，“专注”临时只留居中稿纸。两条竖向分隔线可以拖动调整栏宽；聚焦分隔线后也可用左右方向键微调，双击恢复默认宽度。文件栏是否展开及两侧栏宽度会保存在本机界面偏好中。

点击“专注”会暂时隐藏文件栏、搭档栏和调宽线，只保留居中的稿纸；点击“退出专注”后恢复进入前的两侧栏状态，不会关闭对话或丢失未保存内容。`Ctrl+\` 同样进入或退出专注写作。

### 钉住对照

写某一章时常要盯着一张人物卡、一条设定或大纲。在文件树里右键任意 Markdown / TXT 选「钉在旁边」、在卡片详情页点钉住按钮，或用命令面板「钉住当前文件」，稿纸右侧会多出一栏只读对照，位于稿纸和搭档栏之间，有自己的调宽线（260–560px）。人物卡和世界书按字段列出，章节和其他文本去掉文件头后原样显示；对照栏顶部可以取消钉住或在稿纸里打开该文件。一次只钉一份，再钉别的会替换；文件被改动后对照栏自动刷新，文件被删除则自动取消。专注模式会一并隐藏对照栏，退出后恢复。钉住的路径和栏宽保存在本机界面偏好中，作品里找不到该文件时会静默取消。

顶栏可在纸 / 墨主题之间切换；选择会写入 `localStorage["dsh-editor.theme"]`，并与设置里的外观同步（纸对应浅色，墨对应深色）。首次进入还会参考系统 `prefers-color-scheme`。

### 常用快捷键

本版本没有专门的快捷键弹窗；只保留下列操作，所有快捷键都直接生效，不需要先开对话框：

- `Ctrl+S` 保存当前章节
- `Ctrl+B` 折叠 / 恢复左侧文件栏
- `Ctrl+J` 折叠 / 恢复右侧写作搭档
- `Ctrl+L` 聚焦右侧对话输入框
- `Ctrl+\` 进入或退出专注写作
- `Ctrl+K` 打开或关闭命令面板
- `Ctrl+,` 打开设置
- `Alt+[` / `Alt+]` 上一章 / 下一章
- `Ctrl+F` 稿纸内查找
- `Ctrl+H` 稿纸内查找并替换
- `Ctrl+Shift+F` 打开跨文件全文搜索
- `Ctrl+Shift+O` 打开作品概览
- `Ctrl+Shift+C` 打开人物卡侧栏
- `Ctrl+Shift+W` 打开世界书侧栏
- `Ctrl+Alt+T` 开关打字机滚动（输入或移动光标时保持当前行居中）
- `Ctrl+Alt+P` 开关段落聚焦（淡化光标所在段落以外的正文）
- `Tab` 采纳当前补全建议
- `Esc` 关闭查找栏，或放弃补全 / 改写建议
- `Ctrl+Enter` 应用稿纸上的选段修改提案

命令面板（`Ctrl+K`）还可以新建 / 打开 / 导入作品、导出全文、打开已归档、跳转到文档、切换主题和打开设置。

## 写作

尚未打开文档时，中央稿纸显示与首页相同的封面，并提供“新建文件”。

正文编辑后约 800 毫秒自动保存，也可以按 `Ctrl+S` 或点击“保存”。

如果文件同时被其他程序修改，DSH Editor 不会静默覆盖。你可以重新载入磁盘版本，或先保存带时间戳的冲突副本再重新载入；放弃本地草稿前会在工作台内再次确认，取消后草稿原样保留。保存冲突期间不能用 `Ctrl+S` 绕过。

临时草稿会帮助恢复意外退出前的内容，但草稿不是备份；重要作品仍应定期复制或纳入版本管理。多窗口同时打开同一作品时，草稿按窗口隔离；编辑器底部可以列出并采纳其他窗口留下的备份。

### 查找与替换

当前稿纸内可用 `Ctrl+F` 查找、`Ctrl+H` 查找并替换。跨文件的全文搜索与「全部替换」见下文「作品管理」。

### 正文操作菜单

正文右键与稿纸标题栏“⋯”提供同一组操作：撤销、重做、剪切、复制、粘贴、全选、保存、当前文档查找与替换、光标处补全、选段改写、校对，以及本章工作笔记。生成停止、候选、改写预览、冲突和备份恢复在需要时出现；打字机与段落聚焦在设置 → 写作中调整。

右键落在选区内会保留选区，落在外面则移动光标；「⋯」、`Shift+F10` 和菜单键使用当前选区。方向键可导航，`Esc` 关闭并返回编辑器；查找框和弹窗打开后接管焦点。中文组字期间不会打开菜单。

剪切会先确认复制成功再删除，失败时保留正文并提示；粘贴仅插入纯文本，可单独撤销。等待剪贴板期间编辑正文、切章或重新载入，会取消过期操作。空剪贴板不会删除选区。没有选区时不能剪切、复制或改写；选中文字时不能补全。加载期间不能编辑；生成期间不能再次启动补全或改写，继续编辑会取消旧生成；出现冲突时禁止保存和生成，仍可整理或复制本地草稿。关闭写作辅助后不会发送生成请求。

### 稿纸、排版与打字机

设置 → 写作 →「稿纸与排版」可即时调整打字机滚动、段落聚焦、字号（14–28px）、行距、段距、衬线 / 无衬线 / 等宽字体，以及窄栏（60ch）/ 中栏（76ch）/ 通栏。改动立刻作用到稿纸，并保存在本机 DSH 设置。命令面板也提供打字机与聚焦的快捷开关；`Ctrl+Alt+T` / `Ctrl+Alt+P` 同样生效。

### 专注模式

顶部“专注”或 `Ctrl+\` 只留居中稿纸，见上文「调整工作台布局」。

### 章节切换

稿纸顶部的 `‹ ›` 按完整 `正文` 目录自然排序切换章节，即使文件夹尚未在树中展开也不会漏章。也可以用 `Alt+[` / `Alt+]`。存在未保存内容或版本冲突时，章节切换会暂停，避免丢失当前编辑。

### 章纲与章末状态

打开 `正文/` 下的 Markdown 章节时，从正文右键或稿纸「⋯」菜单选择「本章工作笔记」，会打开「本章工作笔记」弹窗，内含「章纲 / 章末状态」表单。章纲一行一条（最多 12 条、每条 120 字），章末状态是五个短字段：此刻、地点、已知、已了结、未了结，合计不超过 300 字。点「写入」后这些内容以 YAML frontmatter 写在章节文件头部，先进入本地草稿，再按普通保存路径落盘；没改的字段不会被重写，清空即删除。稿纸上不显示这段文件头，字数统计也只算正文；`.txt` 章节不支持。

```yaml
---
beats:
  - 林见在码头等船，天快亮
  - 海关的人先到了
state:
  now: 林见被带走
  where: 港口海关
  knows: 她知道是谁报的信
  open: 船到底有没有靠岸
---
```

这些字段有两个用途：给助手看，和给你自己看。「补全」「修改选段」只带本章的章纲与上一章（按自然顺序的前一章）的章末状态，不会把更早章节的状态或别的章纲混进来；对话中的助手按需读取章节工作笔记。上一章的状态在打开章节时读一次，上一章保存后会刷新。作品概览的章节行会出现「纲 / 态」小标，方便看出哪些章还没写章纲。导出时文件头会被去掉。

## 使用写作助手

右侧可以自由讨论剧情、人物、设定和文字。应用会读取作品根目录的 `AGENTS.md` 作为本项目的长期写作与协作规则；文件缺失时使用默认约定，存在大小写冲突或读取失败时会明确报错。可在文件树中打开这份文件编辑，保存后供后续请求使用。

人物卡、世界书、总纲与作品索引由助手根据当前任务查找和阅读。0.1.8 不再每次固定注入这些资料，也不再按世界书触发词自动注入；旧文件和 frontmatter 可以保留，原来的触发词 / 启用 / 优先级表单已移除。需要某条设定时，在消息中点明文件或条目；人物与设定详情页仍可修改当前支持的结构化字段。

发送内容包含本轮请求和当前文档位置，不会把未保存稿纸当成已保存资料。长期项目约定写入根目录 `AGENTS.md`，一次性要求写在当轮消息里。

讨论、构思、写作、审读可以在同一段对话里自然切换，不需要选择工作模式。写作助手会在有帮助时静默参考内置的小说创作经验；这些参考不会覆盖你的正文、设定或当次要求。助手也可以在动笔前向你提出少量简短问题。

跨作品作者偏好与已确认侧写由系统提示词单独带入；本轮明确要求优先于项目规则，项目规则优先于跨作品默认偏好。旧对话保留历史记录，但旧版固定注入资料不会继续作为新一轮的材料。

### 补全与选段修改

把光标放在正文中，在右键或「⋯」菜单选择“光标处补全”，应用会在当前光标处生成一段建议；建议只显示在稿纸上，不会自动写入。点击“接受补全”或按 `Tab` 才会加入草稿，点击“放弃”或按 `Esc` 则保持正文不变。生成较慢时可以点击“停止补全”。不满意时可点“再来一个”，最多保留三条并用“上一条 / 下一条”比较；新请求失败或返回重复内容时，已有候选不会丢失。

如果在设置里开启“停顿后提示”，只有当前稿纸仍聚焦、光标没有选中文字、光标前已有足够正文且本次编辑尚未提示过时才会请求。继续输入、切换文档、出现版本冲突或已有建议时都会取消旧计时；失败不会在没有新输入时循环重试。自动提示只用于 `正文` 章节，不会用于大纲、人物卡或世界书。

选中文字后，在右键或“⋯”菜单选择“选段改写”，直接输入这次的修改要求。生成后会显示原文与修改后内容，点击“应用修改”才替换原选区；点击“放弃”保留原文。应用可以单独撤销。生成期间继续输入或切换文档会停止旧请求，避免把过期结果写入新内容。

改写要求在独立弹窗中填写，最多 400 字。提交前若正文已经变化，本次操作会取消。没有选中文字时，选段改写不可用。

搭档栏顶部的“展开阅读”可以加宽对话，“恢复宽度”回到展开前的尺寸。普通长回复不会被自动截断；思考强度收在输入区的次级菜单里。

### 提案确认

写作助手不能直接改稿。它提出文件修改时，界面会显示原文与修改后内容，或新文件内容。只有点击“应用”后才会写入；点击“忽略”不会产生任何修改。如果文件已经变化，旧建议会失效，避免覆盖新内容。

### 对话管理

搭档栏顶部可以切换当前作品已有的对话，也可以用铅笔按钮在应用内修改对话名称。铅笔旁的 ⋯ 菜单提供归档、恢复和删除。归档后对话离开主切换列表，出现在「已归档对话」可展开列表里，随时可以恢复；删除会先确认不可撤销，然后从切换列表和已归档列表中永久移除。当前 DSH 客户端没有会话删除接口，删除只在本作品设置里记为墓碑并忘掉标题，不会留下无法从界面找回的隐藏对话。只剩一段对话时不能归档或删除，需要先新建另一段。存在尚未发送的输入时，切换对话、新建对话、归档、删除或返回作品列表前都会在工作台内确认；取消后输入和当前对话原样保留。打开设置是覆盖层，不会丢弃输入。不同对话的草稿和发送状态不会混在一起。没有手工命名的新对话会在第一条助手回复出现后生成简短名称，手工名称始终优先。

点击“新对话”后先选择本次使用的模型，再开始一段新的讨论。输入框下方显示当前模型；展开模型列表时可查看提供方。输入消息时按 `Enter` 发送，按 `Shift+Enter` 换行；中文输入法还在组合文字时不会误发送。主要界面使用简短的操作状态；需要排查问题时可展开错误详情。

## 资料

侧栏“人物 / 设定”、命令面板“人物卡 / 世界书”，或 `Ctrl+Shift+C` / `Ctrl+Shift+W`，会在文件栏打开卡片列表。人物按身份分组，设定按分类分组；可用文字、身份/分类芯片和标签筛选。点一张卡片会用详情页替换中间稿纸（未保存的正文草稿仍留在后台）。“新建人物卡 / 新建设定”会提示标题，写入 `人物卡/` 或 `世界书/` 后打开该 Markdown。

详情页编辑结构化 frontmatter 后点“保存”，写回文件头并带上当前版本；若磁盘上已经变化，会提示并重新读取，不会覆盖别人刚改的内容。点“打开正文”在稿纸里打开该 Markdown；点“引用”才去正文里搜这一张卡的名字、别名或触发词，结果按章节分组，点击一行会打开该章并定位到匹配范围。不会在打开列表时对全部卡片扫引用。

人物卡常用字段：

```yaml
---
name: 林见
aliases: [巡卫林]
role: 主角
gender: 男
age: 十七
faction: 北城巡卫
tags: [刀客]
status: 在场
relations:
  - to: 阿秀
    kind: 旧识
summary: 北城巡卫，守港夜班。
---
```

世界书详情页支持分类、标签和摘要；文件头可保留旧版或手工维护的其它字段：

```yaml
---
triggers: [港口, 海关]
enabled: true
priority: 8
category: 地点
tags: [水路]
summary: 入港盘查与夜禁。
---
```

`category` 可选地点 / 势力 / 物品 / 规则 / 历史 / 其他，也可以自己写。其它 frontmatter 字段可在稿纸中手工编辑；`triggers`、`enabled`、`priority` 不再控制对话的自动注入。树里新建、重命名或删除 `人物卡/`、`世界书/` 下的文件后，侧栏列表会跟着刷新。

## 作品管理

### 作品概览、章节状态与写作曲线

侧栏“概览”、命令面板“作品概览”或 `Ctrl+Shift+O` 会用作品概览替换中间稿纸（稿纸仍挂在后台，未保存草稿不会丢掉）。概览顶部是章节数、总字数和草稿 / 修订中 / 已定稿的分布条；下面按自然顺序列出各章标题、字数、修改时间和状态。点标题打开该章；空章会标出。状态下拉框可改为草稿、修订中或已定稿，先立即改界面，失败时提示并还原。文件树里正文章节行末也会出现对应的草 / 修 / 定小标。

“字数分布”按章画一条简单柱状图。“写作曲线”显示近 30 日每日增量（今日加亮）和近 12 周合计，并列出最近编辑的章节。成功保存正文后约 5 秒会静默记下当天总字数，供曲线使用，不会挡住保存。

### 全文搜索

跨文件全文搜索走侧栏“搜索”、命令面板“全文搜索”或 `Ctrl+Shift+F`：可在整个作品或仅正文中查找字面量，结果按文件分组并显示摘录。点击一处会打开该文件并选中匹配范围；当前文档有未保存内容时会先阻止跳转。

搜索框下方的「替换为」配合「全部替换…」可以把所有命中一次改掉，典型用途是给人物或地名改名。点击后面板内先列出涉及的文件数、命中数和每个文件的命中数，确认后才逐个文件写入。写入前会核对文件版本和命中位置是否仍与搜索时一致；期间被改过的文件会跳过并在结果里标出，可点「重新搜索」再处理。替换的是搜索返回的精确位置，不区分大小写这一点与搜索一致。当前文档在替换范围内且有未保存内容时，整个操作会先被阻止；替换完成后当前稿纸自动重新载入。

### 校对

桌面校对目前暂停使用，顶栏、正文菜单和命令面板不再提供校对入口。已有的校对名单和结果文件保留。

### 导入

首页“导入已有 Markdown / TXT”、作品菜单或命令面板的“导入作品”，会先建立（或选中）一个空作品，再选择源目录。预检通过后把可见的 Markdown / TXT 复制进 `正文/`，源目录不会被修改。TXT 保留文本内容，扩展名改为 `.md`；隐藏路径、链接和非文本会跳过。当前文档有未保存内容时会先要求保存。

完整导入不能整单撤销。中断后可重新选择原来的源目录继续，也可以安全清理：只会删除导入清单中记录且内容未变化的文件，不会删除目标文件夹或其他文件。

### 导出

作品菜单的“导出 Markdown / 导出 TXT”、或命令面板的“导出全文”，会先预检 `正文/**/*.{md,txt}`：按自然章节顺序列出空章警告和总字数，再把同一份整理结果下载为合并后的 Markdown、TXT、DOCX 或 EPUB。预检对话框里可以选择格式；DOCX / EPUB 会在本机打包后下载为「作品名.docx」或「作品名.epub」。当前文档有未保存内容时会先要求保存。合并在本机完成，不会改作品目录里的文件。

### 归档与恢复

在文件树中右键单个可见的 Markdown / TXT，选择“归档”，会把该文件移入可恢复归档。不能归档目录，一次只能归档一个文件。作品菜单或命令面板的“已归档”可以查看、继续未完成操作或恢复；恢复不会覆盖已经存在的同名文件。损坏的归档会计数展示，但不会当作可恢复项。

右键“删除”会先在确认框说明不可撤销（除非之前已提交到历史），确认后删除该文件或整个文件夹。删除与归档不同：删除后不能从「已归档」恢复。

### 保存版本与回滚

从文件栏的版本操作中选择“保存版本”，会把当前作品存为一次快照，提交说明自动使用当前时间（`YYYY-MM-DD HH:mm`）。点“历史版本”查看已保存的版本，任意一条都可以“回滚”：作品内容回到该次提交的状态，回滚前的当前状态会先自动保存为一次新提交，因此回滚本身随时可以撤销。快照只覆盖作品内的 Markdown/TXT 文本；图片等其他文件不会被快照或回滚影响。`.dsh-editor/` 下的旁路文件也不进入快照。

### 文件树操作

在文件树中右键任意文件或文件夹，会弹出操作菜单：新建文件 / 新建文件夹、复制、剪切、粘贴、重命名、归档、删除；正文章节还多出拆章与合章。复制 / 剪切先把条目放进内部剪贴板，再到目标目录（或其中任意一行）的右键菜单里“粘贴”；复制的条目可以反复粘贴，剪切粘贴一次后剪贴板自动清空。复制遇到同名会自动改名（如 `第一章 2.md`），移动和重命名遇到同名会提示并取消。当前文档有未保存内容时，剪切它所在的文件或目录会先被阻止。

### 拆章与合章

右键正文 Markdown 章节选「拆章…」，或在稿纸里把光标放到要切开的段落、用命令面板「在光标处拆章」：对话框里填锚点（从命令面板进入时预填光标所在段落）和新文件名（默认按原名加「-下」或数字加「-2」，在同一目录下取不存在的名字）。锚点必须在文件里恰好出现一次。确认后并不直接改文件，而是弹出与写作助手相同的提案卡，可以先看拆分预览，再点「应用」；应用后打开新文件。

右键选「合并到上一章」或「与下一章合并」，会把两章按自然顺序合成一章：前者把本章接到上一章末尾，后者把下一章接到本章末尾。被并入的那一章会自动归档，可从「已归档」恢复。这两项同样先过提案卡确认；`.txt` 章节不能拆章，也不能与非 Markdown 的邻章合并。相关文件有未保存内容时会先被阻止。

## 设置

首次启动仍可直接进入作品区。顶栏末端的设置控件、写作搭档顶部的“设置接口”以及 `Ctrl+,` 打开的是同一个设置弹窗。

### 模型

“模型”分区管理接口、模型与凭据，首次使用引导也由 DSH 处理。密钥只交给 DSH 的私有凭据存储，界面不会读取或回显明文。

这里可以分别选择“补全模型”“改写模型”“默认对话模型”。补全和改写留空时跟随当前对话；默认对话模型只用于新开的对话，已有对话仍保留自己的选择。

### 写作

“写作”分区只保存编辑器自身的偏好。内容区可上下滚动，窗口较小时也能到达底部的作者约定与保存按钮。默认“仅手动”，只有从正文菜单选择“光标处补全”时才请求；改为“停顿后提示”后，仅在 `正文` 章节中连续输入并停顿约 1.5 秒时生成一次建议。自动提示不会用于大纲、人物卡或世界书，也不会直接写入，仍需点击“接受补全”或按 `Tab`。

“跨作品作者约定”用于维护不属于某一本书的稳定偏好，例如叙事人称、行文禁忌或协作习惯。最多 1,200 字，保存在本机 DSH 设置中，不会写进作品目录；输入后点击“保存作者约定”。所有作品的搭档、行内补全和选段修改都会参考。旧版浏览器偏好会在首次启动时迁移；迁移失败时原值会继续生效，并可在“写作”分区重试。它不是本书设定，也不会改变文件权限或代替你本轮提出的要求。某一本书独有的规则仍应写入该作品的“项目总览”、人物卡或世界书。

### 稿纸与排版

同一分区的「稿纸与排版」控制打字机、段落聚焦和字号 / 行距 / 段距 / 字体 / 纸宽，见上文「稿纸、排版与打字机」。

### 语言与外观

“通用设置”里可以改语言、外观，以及智能体运行时的 Enter 键行为（排队发送或插话发送；`Ctrl+Enter` 使用另一行为）。

「语言」可选中文或 English，切换后立即生效、不需要重启，只覆盖编辑器外壳界面；右侧 DSH 对话区仍使用其自带文案。

「外观」可选浅色、深色或跟随系统，与顶栏的纸 / 墨切换互通。跟随系统没有对应的稿纸主题，读取时会按系统偏好落成纸或墨。

### 插件

“插件”按作者用途组织内置功能：写作辅助、校对、作品概览、人物与世界书、写作记忆、知乎资料。一个开关控制该功能的相关入口；详情可以查看组成。稿纸、写作界面与插件管理本身不能关闭。若提示未能保存，可重试；用户自己改过的受保护配置会保留。社区插件仍按安装包管理，可以检查和卸载。市场页搜索带 `dsh-plugin` 主题的 GitHub 仓库，也可以直接填写 `owner/repo`。安装前可用「检查」做静态判断：有没有构建产物、会不会抢写作界面的 root、入口文件能不能被 Loader 解析。检查通过也不保证运行时一定成功。安装与卸载后需要重启应用；作品文件、对话和设置不会被删除。

### 用量

“用量”分区显示本机过去 30 天的模型调用统计：今日概览和近 7 日分模型柱状图。图表提供日期、刻度和悬浮明细，也可展开精确数据；没有调用的日期按零显示。只统计本机用量，不含费用估算。

### 知乎资料

在设置中打开“知乎资料”，用于填写知乎开放平台 Access Secret，让搭档调用站内搜索、全网搜索、热榜、直答和公开知识库检索。桌面顶栏不再提供知乎查询按钮。也可在此查看近 30 天的知乎调用用量，以及把参考资料上传到知乎知识库。文件会保存到知乎云端，请勿上传未发表手稿。

## 更新与安装

顶栏的“关于”按钮打开“关于 DSH Editor”对话框：显示当前版本，并可以从 GitHub Releases 检查新版本；发现新版时会给出发布说明，可以直接在对话框里“下载更新”——下载优先走 GitHub 镜像，全部失败后回退直连，下载完成会按发布页附带的 SHA-256 校验和验证文件完整性。Windows 安装版点“退出并安装”后由安装向导覆盖安装；Windows 便携版点“重启并替换”后应用自动完成 EXE 替换并重启；macOS 没有代码签名，无法自动替换，下载后点“打开所在文件夹”，退出应用并用新版 dmg 中的应用替换「应用程序」里的旧版。下载失败时仍可用“前往下载”经浏览器手动下载。更新前先保存作品。保留旧版本和它的 SHA-256 作为回滚点；如需回滚，关闭新版后重新运行旧版本。当前版本没有代码签名：Windows SmartScreen 可能提示未知发布者，macOS 首次打开需在访达中右键应用并选择“打开”。请只运行可信来源的文件。

## 数据存放

作品目录下的 `.dsh-editor/` 是应用私有元数据，文件树里默认不显示。提交快照时，路径中任一段以 `.` 开头的项都会被排除，因此 `.dsh-editor/*` 一律不进入快照。常见内容包括：

- `作品索引.md`：打开已有作品时由搭档阅读现有文本后写入
- `chapter-status.json`：各章草稿 / 修订中 / 已定稿
- `writing-log.json`：按本机日期记录的每日字数，供写作曲线使用
- `敏感词.txt` / `敏感词-忽略.txt`：校对用的追加名单与忽略名单
- `snapshots/`：提交与回滚使用的文本快照
- `archive/`：可恢复归档
- `scratch/`：助手的临时工作草稿，界面不显示，不进入对话上下文，也不进入快照

这些旁路文件缺失或损坏时，对应功能会退回默认值，不会挡住正文编辑。不要把手稿只放在 `.dsh-editor/` 里。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无法连接模型 | 检查接口地址、Key、额度和网络，再重新连接。 |
| 保存冲突 | 重新载入磁盘版本，或先另存冲突副本。 |
| 建议无法应用 | 文件已经变化；让写作助手根据最新内容重新提出建议。 |
| 想恢复归档或导出现稿 | 作品菜单打开“已归档”恢复；导出走作品菜单或命令面板的预检下载，可选 Markdown / TXT / DOCX / EPUB。 |
| 删了文件却找不到归档 | 右键“删除”是永久删除；只有“归档”才能从「已归档」恢复，且一次只能归档单个 Markdown / TXT。 |
| 主题不对 | 顶栏切换纸 / 墨，或到设置 → 通用设置改外观；选择会写入 `localStorage["dsh-editor.theme"]`，首次进入还会参考系统 `prefers-color-scheme`。 |
| 想找正文中的某段文字 | 当前章用 `Ctrl+F` / `Ctrl+H`；跨文件用 `Ctrl+Shift+F` 或侧栏“搜索”；章节仍可用 `Alt+[` / `Alt+]` 翻。 |
| 想看全书字数或改章节状态 | 用 `Ctrl+Shift+O` 或侧栏“概览”。 |
| 想检查标点、错别字或敏感词 | 用 `Ctrl+Shift+L` 或侧栏“校对”；忽略名单在 `.dsh-editor/敏感词-忽略.txt`。校对自动应用只支持 Markdown，`.txt` 请手工改。 |
| 想改人物卡或世界书字段 | 用 `Ctrl+Shift+C` / `Ctrl+Shift+W` 或侧栏“人物 / 设定”；其它文件头字段在稿纸中手工编辑。 |
| 删掉的对话还能找回吗 | 不能。删除只在本机记墓碑，DSH 没有会话删除；归档过的对话可以恢复，删除过的不能。 |
| 改了语言，对话还是原文案 | 「语言」只覆盖编辑器外壳；右侧 DSH 对话区仍使用其自带文案。 |
| SmartScreen 或 Gatekeeper 警告 | 当前版本没有代码签名；核对可信来源和 SHA-256。Windows 可能提示未知发布者，macOS 首次请在访达中右键打开。 |
| 启动后不是写作界面 | 保存截图和诊断信息并联系开发者。 |
