# 使用指南

## 安装与更新

从 [GitHub Releases](https://github.com/klarkxy/dsh-editor/releases) 下载。Windows 可运行便携版 EXE 或安装器；macOS 将 dmg / zip 中的应用拖入「应用程序」。便携版首次启动需要准备本地环境，可能稍慢。

应用未签名，Windows 可能提示未知发布者，macOS 首次可在访达中右键选择「打开」。只运行可信来源的文件。

更新前保存作品，在「设置 → 关于」检查和下载更新：

| 平台 | 下载完成后 |
| --- | --- |
| Windows 安装版 | 点「退出并安装」 |
| Windows 便携版 | 点「重启并替换」 |
| macOS | 打开下载文件夹，退出应用，用新版替换旧版 |

下载会核对发布页的 SHA-256；失败时可前往发布页手动下载。保留旧版安装包，以便关闭新版后回滚。

0.4.x 系列更新包含 DSH 运行时升级。更新前请备份作品文件夹和应用数据目录：Windows 为 `%USERPROFILE%\.dsh-editor`，macOS 为 `~/.dsh-editor`；若设置了 `DSH_HOME`，备份该目录。回退旧版时，先退出应用，再恢复更新前的应用数据备份；仅保留旧安装包不能还原已迁移的配置与会话。

## 打开作品

首页「新建」按作品名在「文档/dsh-editor」下建立文件夹；「打开作品」直接打开已有文件夹。同名目录不会被覆盖。

新作品从空白开始。在稿纸上点「写第一篇」，后续用文件栏「新建文档」继续。新建文件夹在「目录操作」或文件树右键菜单中。也可以先与搭档讨论人物、设定和大纲，采用提案后再写正文。目录按需创建，已有 Markdown / TXT 可直接使用。

顶部作品名菜单可切换最近作品、打开或新建作品、导出与返回首页。从最近列表移除入口不会删除作品。

## 写作与保存

中间是稿纸，左侧是文件树，右侧是写作搭档。顶栏可收起两侧栏或进入专注模式；宽屏下拖动分隔线调整栏宽。右键文件选「钉在旁边」可打开一份只读对照。

正文自动保存，`Ctrl+S` 可立即保存。切章或离开作品前会先保存；遇到失败、冲突或尚未保存的新输入时，先处理当前文档再继续。

文件被其他程序改过时，可重新载入磁盘版本，或先另存冲突副本。临时草稿可帮助恢复意外退出前的内容，但不能代替备份。

正文右键和标题栏「⋯」提供编辑、查找、补全与改写操作。「设置 → 写作」调整字体、字号、行距、纸宽、打字机滚动和段落聚焦。

稿纸菜单中的「选中当前段落」复用聚焦段落的空行分隔规则，仅改变可见稿纸中的选区，不改变文件内容，也不会选中隐藏的文件头。选中后可继续使用现有的复制或改写操作。它不是 Markdown 语法树选块，也不会给段落生成持久化 ID。

## 与搭档协作

在「设置 → 模型 → 供应商」连接模型，再分别设置新对话、正文补全和选区改写的模型。未单独指定时，新对话使用 DSH 默认模型，补全和改写跟随当前会话模型，再回退到 DSH 默认模型。插件自身的模型选择位于各插件配置页。默认对话模型只影响新对话；模型失效或保存失败会显示错误。

- **补全**：光标处选择「光标处补全」或按 `Ctrl+Enter` 手动补全（有改写预览时接受改写），`Tab` 接受、`Esc` 放弃；可停止生成或比较候选。「停顿后提示」在写作设置中开启，仅用于正文。
- **改写**：选中文字，选择「选段改写」并填写要求；预览后应用，可撤销。
- **文件提案**：正文与大纲的修改或新建先出可预览提案，点「应用」才写入。文件变化后，须基于最新内容重新提案。
- **规划**：大纲与章纲走提案、经作者采用后生效；人物卡与世界书是普通 Markdown，由搭档在协作中自动维护、写入即生效，历史可在记忆面板查看并撤销。没有强制的章节收尾步骤。

「新对话」可选择通用写作、小说创作、文章与自媒体、技术文档；模式创建后固定，模型可随时换。`Enter` 发送，`Shift+Enter` 换行。

对话菜单提供重命名、置顶、归档、恢复，以及「隐藏已归档／全部对话／仅显示已归档」筛选。置顶改变列表顺序，归档可恢复。正在运行的对话需要确认停止后才能归档；只剩一段对话时，须先新建另一段。标题、归档与置顶均沿用 DSH 原生会话状态。

「设置 → 助手」中的作者约定适用于所有作品，需要点击「保存作者约定」后生效；未保存草稿在当前工作台中关闭、重开设置后仍保留；退出应用前仍需保存。本书独有的规则放在作品的 `AGENTS.md`、人物卡或世界书，由搭档在协作中自动维护，历史可在记忆面板查看并撤销；辅助规则文件在作者文件树中隐藏，可用外部编辑器维护。


## 管理作品

| 操作 | 入口与注意事项 |
| --- | --- |
| 查找替换 | 当前稿纸用 `Ctrl+F` / `Ctrl+H`；跨文件用 `Ctrl+Shift+F`。「全部替换」先预览再确认，已变化的文件会跳过，可重新搜索处理。 |
| 移动与重命名 | 文件树右键菜单；也可拖到目标目录。移动、重命名遇到同名会取消，复制会自动改名。 |
| 拆章与合章 | 正文 Markdown 的右键菜单。拆章锚点须唯一；合章会移出被并入的章节。两者先预览提案，再确认应用。 |
| 保存与回滚版本 | 文件栏「目录操作 → 保存版本 / 历史版本」。自动保存只更新文稿，不自动创建历史版本。回滚前自动保存当前状态；快照只覆盖 Markdown / TXT，不包括图片和隐藏文件。 |
| 导出 | 作品菜单「导出稿件」，预检顺序、空文档和字数后选择 Markdown / TXT / DOCX / EPUB。 |
| 删除 | 文件树右键「删除」；永久删除，除非此前已保存到历史版本，否则无法恢复。没有文档归档入口。 |

备份或迁移作品时复制整个文件夹，包括隐藏的 `.dsh-editor/`。不要把正文只放在这个元数据目录中。

## 官方 DSH 功能

Editor 保留稿纸和写作搭档界面，通过 DSH 的公有布局合同与界面槽位加载官方插件。官方定时任务不在此发行组合中。

| 功能 | 使用方式 |
| --- | --- |
| 资料预览 | 在文件树点图片、PDF、`.doc` / `.docx`、`.ppt` / `.pptx`、`.xls` / `.xlsx`、`.csv` / `.tsv` 文件，在资料栏查看；Markdown / TXT 仍在稿纸中打开。 |
| MCP 资源 | 默认关闭；在「插件」页启用「MCP 资源」，资源来自已经配置的 MCP 服务。 |
| 语音输入 | 随包提供但默认关闭：先在「插件」页开启「语音输入」，再进入准备页；需要本地识别模型时，由你选择下载和准备。准备完成后，对话输入区才出现麦克风，把转写放入当前对话草稿。下载大小和首次运行时间取决于模型与环境。 |
| 快捷键 | 「设置 → 快捷键」使用官方搜索、录制和重置界面；桌面版保存自定义按键，重启后继续使用。 |

## 辅助功能与设置

全局「插件」按钮打开独立插件页。已安装清单、配置、安装、检查、进度、脚本批准、取消、启用和移除由官方插件管理器单独负责。必需模块只读。已安装插件的配置在官方插件页中打开。发现搜索与写作模式是补充入口，默认收起。

发现插件：留空点「搜索」列出本机可选包（含人物卡等随包私有名称）；也可输入关键词、npm 包名或 GitHub 仓库。结果只复制安装规格，请在官方页用「添加插件」粘贴。未写版本的本机包名优先匹配本地绝对 `link:` 规格；写明 npm 版本或 GitHub 规格则走官方安装。作者移除的可选包升级后保持移除，自选版本予以保留；移除后的随包来源仍可搜到并再次添加。网页搜索随桌面版预装。知乎、当前标题、需求记录和会话纪要不再预装，可搜索 `npm:@klarkxy/dsh-zhihu` 后按官方流程安装。已安装的 npm 包可打开官方详情。

写作模式：与官方安装清单分开，由 Editor 管理第一方 preset。通用写作不可关闭；其余模式只影响新对话。

发现搜索见[插件适配](../packages/dsh-editor-plugins/README.md)。

| 功能 | 入口与说明 |
| --- | --- |
| 文稿校对 | `Ctrl+Shift+L` 或命令面板「校对当前文档」；[检查范围与名单](../packages/dsh-editor-proofread-panel/README.md) |
| 文档概览 | 作品菜单「文档概览」或 `Ctrl+Shift+O`；[字数与写作曲线](../packages/dsh-editor-overview-panel/README.md) |
| 人物与世界书 | 文件树直接编辑；[可选目录快捷入口](../packages/dsh-editor-cards/README.md) |
| 写作记忆 | 按需开启；查看规则、人物卡与世界书的维护历史并撤销写入，[面板说明](../packages/dsh-editor-memory-panel/README.md) |
| 知乎资料 | 按需安装 `npm:@klarkxy/dsh-zhihu` 后在插件页配置；[使用与上传须知](https://github.com/klarkxy/dsh-plugins/blob/main/plugins/dsh-zhihu/docs/README.zh-CN.md) |
| 网络搜索 | 预装，在插件页选择后端；[配置与费用](https://github.com/klarkxy/dsh-plugins/tree/main/plugins/dsh-web-search-manager/docs/README.zh-CN.md) |

「通用设置」调整中英文、外观及搭档忙碌时的发送方式。「用量」显示本机模型调用记录，不是费用账单。

## 快捷键

以下是 Windows 桌面版默认按键；macOS 请以「设置 → 快捷键」中的显示为准。可在该页搜索、录制或重置工作区与窗口命令，自定义结果保存在桌面应用数据中；下表的编辑命令需先聚焦稿纸。Web 的部分默认组合键不同，例如段落聚焦为 `Ctrl+Shift+P`。

| 按键 | 操作 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+K` | 命令面板，查找其余命令与快捷键 |
| `Ctrl+Shift+N` | 新建窗口 |
| `Ctrl+,` | 设置 |
| `Ctrl+B` / `Ctrl+J` | 文件栏 / 搭档栏 |
| `Ctrl+L` | 聚焦搭档输入框 |
| `Ctrl+Alt+F` | 专注模式 |
| `Ctrl+Alt+P` | 段落聚焦 |
| `Ctrl+F` / `Ctrl+H` | 稿内查找 / 替换 |
| `Ctrl+Shift+F` | 跨文件搜索 |
| `Ctrl+Enter` | 手动补全；有选段修改提案时接受提案 |

## 按词审稿与按需查资料

选段改写的预览会分别标出删除和新增的词语，中文按词比较，并保留原来的空白、标点和换行。超长或差异过多的文本会降级为较粗的对照，不影响稿纸输入。仍然整项「应用修改」或「放弃」，不支持逐词采纳；正文变化后，旧提案照常失效。差异结果仅用于展示，不参与拼接写入。

在稿纸选中一个名称，通过右键或顶栏更多菜单选择「查相关资料」，按需查询当前文件列表中的 `人物卡/` 与 `世界书/`。文件名和文件正文都可命中，同名但不同路径的资料分别显示。结果可「打开资料」或「钉在旁边」；打开时沿用既有的保存与版本检查，钉住时沿用只读资料栏。查询不需要开启目录快捷入口，不自动建立索引、创建卡片、修改资料或注入模型上下文。搜索失败、跳过或截断会明确提示。

## 遇到问题

模型无法连接时，检查接口地址、密钥、额度和网络。提案失效时，让搭档根据最新文件重新提出；保存冲突先保留副本再重新载入。启动异常时保留诊断信息并联系开发者。
