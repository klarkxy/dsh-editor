## ⚠️ 已知问题

### 1. pnpm 并行构建/检查失败

**问题**: 使用 `pnpm -r --filter` 并行运行时出现 EPERM 错误

**原因**: Windows 文件锁定或权限问题

**解决方案**: 逐个包运行命令

**影响**: 不影响功能，只是需要手动运行多次命令

### 2. pnpm install 内存不足

**问题**: 默认内存限制导致安装失败

**原因**: 项目依赖复杂，需要更多内存

**解决方案**: 设置 `NODE_OPTIONS=--max-old-space-size=8192`

**影响**: 仅影响初次安装，已解决
