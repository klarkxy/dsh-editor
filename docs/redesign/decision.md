## 视觉方向

采用 **B「原稿」**，不和其他方向组合。结构上不加竖向导航，保持：顶栏分组、左栏「文件 / 搜索」页签、右侧辅助栏横向页签「搭档 / 资料 / 工具」。

B 的定稿要点（数值进入 `tokens.ts` 前以本节为准）：

- 浅色：外框 `#E8EBE6`，稿纸 `#F7F8F4`，浮层 `#FFFFFF`，正文 `#1E2420`，次要文字 `#5C655E`，分割线 `rgba(30, 36, 32, 0.10)`。
- 深色：外框 `#151816`，稿纸 `#1C201D`，浮层 `#252A26`，正文 `#DADFD6`，次要文字 `#97A096`。
- 主色：黛蓝。浅色填充 `#2E4F7A` 配白字；深色填充 `#8FB0DE` 配深色字 `#14181B`。链接和焦点用同一色相，并按明暗模式分别保证对比度不低于 4.5:1。
- 朱色只用于版心竖线（35% 不透明度）和树中当前章节前的圆点：浅色 `#B23A2A`，深色 `#E07A68`。
- 作品名、章节标题、首页作品名、分节符用楷体栈 `"Kaiti SC", "STKaiti", "KaiTi", "楷体", serif`。界面文字用系统无衬线，不加载远程字体。
- 稿纸铺满中栏，不做卡片。版心两侧有竖线，天头有一条细线；章节标题在稿纸内居中；字数和保存状态放在页脚。
- 辅助栏与外框同色调，栏内不再套白卡片；页签是文字加 2px 黛蓝下划线；顶栏视图开关是仅图标的按钮，当前项用黛蓝。

## 产品原则的变更

1. **界面视觉基准**：从 DSH 官方 `dsh-v0.2.1-rc.5` 视觉适配，改为本仓库自己的「原稿」设计系统。上游许可证归属保持不变。
2. **连续输入时淡化侧栏**：批准。连续输入时左右两栏降到 55% 不透明度；移动鼠标、按快捷键或焦点移入侧栏时立即恢复。控件始终可以点击，命中区不变；系统开启减少动态效果时，状态直接切换，没有过渡动画。
3. **主题色固定**：去掉作者自选主题色，全界面统一使用黛蓝。作者以前保存的主题色设置不再生效，但存储键原样保留、不删除。
4. 第 1 阶段批准过 C 方向的竖向导航，但未采用，不进入产品原则。

其余产品原则不变：稿纸居中且为主体；常用文字不小于 13px，主控件不小于 32px；不用紫色渐变、玻璃拟态或霓虹 AI 装饰；不把写作台扩展成 IDE；中英双语。
