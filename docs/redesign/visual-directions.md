# 视觉方案简报（G1 前）

> **状态（第 7 阶段验收时）**：历史留档。G1 选定 **B「原稿」** 并已实施完毕；A「静纸」与 C 未采用。共用信息架构 1–9 项全部落地。数值以 `src/design-system/tokens.ts` 与 [界面设计](../ui-design.md) 为准，本文不再是最新来源。

本文是 `redesign/ui-v2` 第 1 阶段的方案规格。三套方案共用同一套信息架构修正，分歧只在视觉语言，C 另外调整导航结构。方案以静态 HTML 呈现，不代表最终实现；G1 选定后，数值写进 `tokens.ts`。依据见 [UX 审计](ux-audit.md)。

## 产品与读者

- 产品：中文长文写作桌面应用，带 AI 写作搭档。
- 读者：写小说、文章和技术文档的中文作者，单次写作时间长。
- 首要任务：在稿纸上写作。其次是向搭档提问和审阅提案。界面其他部分都为这两件事服务，不和稿纸抢视线。

## 三套方案共用的信息架构

以下修正直接回应审计问题，与视觉方向无关。G1 时逐条确认。

1. **顶栏分三组**：左边是位置（作品名菜单、当前文档路径）；中间留空，用作窗口拖动区；右边是视图（文件栏、专注、辅助栏三个开关，做成一个分段控件）和全局入口（命令与搜索、设置）。主题切换移进设置和命令面板，顶栏少一个图标。
2. **左栏用「文件 / 搜索」页签切换**：搜索结果不再把树推下去。树里不显示 `.md`，章节按自然顺序排列，并显示字数。
3. **右侧辅助栏，同时只展开一项**：页签为「搭档」「资料」「工具」。资料预览和钉住对照都在「资料」页里；校对、概览、记忆在「工具」页里。辅助栏是栅格中的一栏，不是覆盖层，专注模式下收起。窄窗下它变成全屏抽屉。
4. **设置和插件合并为一个全页视图**：替换工作台显示，左侧导航为：写作、模型、助手、外观、快捷键、插件（总览、发现、安装与卸载）、用量、关于、高级（破限模式、开发者选项）。写作页右侧显示稿纸的实时预览。插件只保留一份清单。
5. **新对话改为分裂按钮**：主按钮沿用上次的模式直接新建，箭头处展开模式菜单。
6. **选段改写用就近浮层**：浮层出现在选区下方，包含预设标签和一行指令输入框，不遮住稿纸。
7. **右键菜单按对象类型给出**：正文、资料和目录各有自己的菜单。写作操作放在前面并标出快捷键；系统编辑操作收进「编辑」子菜单。
8. **稿纸默认排版**：段间距收紧到 0.25em；可选首行缩进 2em；单独成段的「一」「二」等分节标记按居中的分节符显示，不当作标题。作者已保存的偏好不受影响。
9. **搭档栏空状态**：显示三条按当前文档生成的起步建议，例如「审读这一章的节奏」。点击后只填入输入框，不自动发送。

## 方向 A「静纸」

**想法**：去掉一切表演，界面像一张放在桌上的纸。窗口外框是一条连续的中性色带，稿纸是唯一更亮的面。

- 色彩，浅色：外框 `#F3F3F1`，稿纸 `#FCFCFA`，浮层 `#FFFFFF`，正文 `#1D1D1B`，次要文字 `#66665F`，分割线 `rgba(29, 29, 27, 0.09)`。深色：外框 `#1B1B1A`，稿纸 `#222221`，浮层 `#2B2B2A`，正文 `#E4E3DE`，次要文字 `#9D9C95`。
- 主题色：默认蓝 `#3B5FD9`，作者已保存的主题色照常生效。
- 字体：界面用系统无衬线，13/14px；稿纸默认 17px，行高 1.85。
- 几何：控件圆角 8px，浮层 12px，对话框 16px；平面元素不加阴影，只有浮层有阴影。
- 记忆点：稿纸是唯一带一道极轻投影的平面，像纸放在桌上；其他元素都是平的。
- 风险最低，和现行风格最接近。

## 方向 B「原稿」

**想法**：取中文原稿纸的语汇。版心两侧有极淡的竖线，天头有一条细线；作品名和章节标题用楷体。界面文字仍用无衬线，保证可读。配色避开常见的米色加陶土色，用偏冷的玉白和墨色。

- 色彩，浅色：外框 `#E8EBE6`（青灰），稿纸 `#F7F8F4`，浮层 `#FFFFFF`，正文 `#1E2420`，次要文字 `#5C655E`，分割线 `rgba(30, 36, 32, 0.10)`。深色：外框 `#151816`，稿纸 `#1C201D`，浮层 `#252A26`，正文 `#DADFD6`，次要文字 `#97A096`。
- 主题色：默认黛蓝 `#2E4F7A`，深色下用 `#8FB0DE`。朱色 `#B23A2A`（深色下 `#E07A68`）只用在两处：版心竖线，以及树中当前章节前的小圆点。
- 字体：标题用 `"Kaiti SC", "STKaiti", "KaiTi", "楷体", serif`，正文默认无衬线；不加载远程字体。
- 动效：连续输入时，左右两栏降到 55% 不透明度；移动鼠标或按快捷键立即恢复。这个动效只响应作者的操作。
- 记忆点：稿纸的版心线和楷体标题。
- 可能偏离的原则：写作时界面降低不透明度。所有控件仍可点击、命中区不变，需确认这一点不影响可发现性。

## 方向 C「工作台」

**想法**：面向管理大量文件的作者，信息密度更高、分区更清楚。左侧增加一条 56px 的竖向导航，图标下方带文字，统一现在分散在顶栏、侧栏和命令面板里的入口。

- 色彩，浅色：外框 `#EBEDF0`，侧栏 `#F4F5F7`，稿纸 `#FFFFFF`，浮层 `#FFFFFF`，正文 `#161A1F`，次要文字 `#58606B`，分割线 `rgba(22, 26, 31, 0.10)`。深色：外框 `#15191E`，侧栏 `#1B2026`，稿纸 `#1F242A`，浮层 `#282E35`，正文 `#E2E6EB`，次要文字 `#98A1AC`。
- 主题色：默认青 `#0E7C74`，作者已保存的主题色照常生效。
- 字体：界面 13px；树行 28px 高；稿纸默认和 A 相同。
- 结构：竖向导航依次为：作品、文件、搜索、大纲、工具（校对、概览、记忆）、插件，底部是设置。右侧辅助栏只保留「搭档」和「资料」，工具移到左侧。
- 记忆点：竖向导航和清楚的面板分区。
- 偏离的原则：与「不增加 activity bar」冲突，需要单独批准。
