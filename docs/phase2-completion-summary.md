## 设计决策

| 决策 | 理由 | 权衡 |
|------|------|------|
| 工厂函数 vs 基类 | TypeScript 更好的类型推导 | 需要显式调用 |
| 请求总线用 nonce | 简单有效的去重 | 理论存在冲突 |
| 样式生成 vs 继承 | CSS 不支持继承 | 生成字符串较长 |
| 返回完整 Cordis 插件 | 符合现有模式 | 需理解生命周期 |
| 钩子 vs HOC | React 现代模式 | 需 React 16.8+ |
