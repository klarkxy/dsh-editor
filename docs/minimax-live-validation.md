## 实测发现与已修复的问题

1. **插件样式冲突**：独立校对与作品校对都使用 `.proofread-panel`，改变了原作品面板定位。独立插件已完整使用 `dsh-proofread-*` 类名。
2. **插件入口挡住发送**：原右下角校对按钮覆盖聊天发送按钮。Shell 为扩展入口在顶栏预留布局空间，插件面板仍自行管理请求和关闭；不使用强制点击绕过。官方 Web 保留独立入口的原回退位置。
3. **补全读取历史模型**：`requestHeader()` 表示上次已经执行的请求，不是当前选择；新会话可能返回空文本。可选 assist 现复用 DSH gateway 的当前模型选择，查询失败不会回退到旧模型；普通文件权限和 channel 所有者不变。
4. **推理混入正文**：MiniMax-M3 会在 text-delta 中包含 `<think>...</think>`。收集器现在跨分块过滤推理，再计算正文长度，未闭合的推理块不会成为建议；普通正文换行/缩进保持。请求 token 上限从 FIM96/改写512 调整为1024/2048，给推理留出空间；可见正文仍限制为240/1200字符。
5. **测试误判**：修复“正在生成”被视为补全完成、改写面板使用错误 role 定位、新对话没有等待模型选择就继续操作的问题。最终验收要求实际输出、正常点击和磁盘保存。

最终类型检查通过，96个测试文件的838项回归通过。新增回归覆盖当前模型选择、切换后的新路由、查询错误不回退、推理标签跨分块/未闭合/多块过滤以及正文空白保留。独立评审确认模型选择边界；其提出的正文空白回归也已修复。
