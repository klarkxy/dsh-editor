# 作者优先工作流：前置规划

## 目标

把创作顺序明确为：先讨论，再设计人物卡、世界书和大纲/章纲，作者确认后落笔。正文页只承担写作，不再要求作者在写完后整理本章。

## 产品边界

- 人物卡一人一份，保存在 人物卡/。
- 世界书一词条一份，保存在 世界书/。
- 全书大纲、分卷大纲和章纲统一是 大纲/ 下的普通 Markdown。
- 规划内容先在对话中讨论；需要落盘时生成可预览提案，作者明确采用后才写入。
- 正文页不显示章纲折叠条、章末小结或整理本章。
- 正文菜单和命令面板不提供写后整理入口。
- 新的工具调用不再接受 chapter_plan、chapter_summary，也不通过维护工具写正文 state。
- 旧正文中的 beats/state 原样保留，只作文件兼容；不自动删除，不继续生成。

## 验收

1. 打开正文时，稿纸底部没有章纲或整理本章。
2. 正文右键、标题栏菜单和命令面板均没有章纲、章末小结或整理本章。
3. 助手把章纲写入 大纲/ Markdown 提案，不写入 正文/ frontmatter。
4. chapter_plan、chapter_summary 及 memory chapter_summary 新调用被拒绝。
5. 旧正文的 frontmatter 在保存正文时不被删除或覆盖。
