# 前置规划工作流验收

当前开发版采用“先规划、后落笔”的作者工作流。

- 正文页只保留正文编辑、章节导航、字数、保存状态与通用编辑操作。
- 大纲与章纲统一保存到 大纲/ 下的普通 Markdown。
- 人物卡、世界书和大纲/章纲在对话中讨论，经提案预览与作者采用后落盘。
- 写完正文后不出现整理本章，也不要求补章末小结。
- 提案工具拒绝新的 chapter_plan / chapter_summary；作品维护工具只维护项目规则、人物卡和世界书。
- 旧作品中的 beats / state 不会被迁移、删除或改写，仍可安全打开和保存。

最终验收以当前源码的类型检查、相关单元测试和真实界面检查为准；旧的写后整理测试不再作为通过条件。
