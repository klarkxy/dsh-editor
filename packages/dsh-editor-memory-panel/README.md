# dsh-editor-memory-panel

桌面记忆维护侧栏。默认关闭，在「设置 → 插件 → 记忆维护」开启。

查看搭档自动写入的作品规则、人物卡和世界书维护历史，可撤销写入。文件操作由 [workbench](../dsh-editor-workbench/README.md) 处理，资料仍保存在作品目录。

## 核心流程

写入以待确认（pending）提案到达：搭档维护 AGENTS.md、人物卡或世界书后，先落一条带前后内容与依据的记录，作者点「确认写入」才经 `memory.apply` 落盘；已写入的条目可随时「撤销写入」。

每条记录有五种状态：待确认、已写入、已过期、失败、已撤销。侧栏可按状态筛选（全部 / 已写入 / 已撤销 / 失败），展开条目可见写入前后差异、分类（规则 / 事实）、确定性（明确 / 不确定）与逐条依据（文件路径或「来自对话」加原文引用）。目标文件在写入后又有变化时，撤销不会静默回滚，而是转为一条新的待确认更新，仍由作者决定是否落盘。

## 入口

- 命令面板命令「记忆维护」（id `memory-open`）。
- 侧栏工具项「记忆」。
- 聊天内 `novel_memory_update` 工具的结果卡片：已写入 / 已撤销的默认收起差异，待确认、失败、已过期的默认展开，可直接在卡片上确认或撤销。

## 架构

面板自身不碰文件：列表、详情、确认与撤销都经 `/dsh-editor-workbench` 通道的 `memory.list` / `memory.get` / `memory.apply` / `memory.undo` 完成，维护记录与实际写入都由 workbench 管理。
