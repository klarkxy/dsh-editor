# 人物

人物不只是性格标签。观察他长期想要什么、此刻具体要什么、知道什么、误信什么、害怕失去什么，以及他愿意采取和拒绝采取的手段。真正能推动故事的人物拥有行动权、拒绝权和承担后果的责任。

关系写成动态状态：谁依赖谁、谁欠谁、谁掌握信息、谁有正式或非正式权力、双方最近一次互动留下了什么余温。关系变化应由可见行为积累，而不是一句旁白宣布。

区分作者知道、人物知道和人物以为自己知道。人物的决定只能使用其当时可获得的信息。连续场景之间要携带伤势、物品、承诺、情绪余波、公开信息与秘密状态。

人物声音来自注意力和判断习惯，而不只来自口头禅：同一房间里，有人先看出口，有人先看衣料，有人先看谁没说话。让人物在压力下暴露取舍，同时保留矛盾和变化空间；避免把角色压扁成剧情功能或观点喇叭。
