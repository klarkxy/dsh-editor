# 正文与场景

先让读者站稳：尽快提供必要的人物、地点、时间感、当前动作和即时关注点，但只给理解本场所需的上下文。场景通过动作、对白、感知和反应相互承接；环境细节经过视角人物的需要与偏见，而不是作为独立布景清单出现。

每一段优先完成一个清楚任务。人物做了什么，别人或环境怎样回应，这个回应又怎样改变下一动作。关键变化落在可观察的行为、身体感受、选择或具体细节上，不用抽象总结替代戏剧过程。

低冲突不等于无动力。可以写共同劳动、谨慎靠近、疲惫后的沉默、误解的轻微积累或无法明说的照顾；仍需有期待、阻力和小幅变化。

写作时只使用已确认事实，未知处不要擅自补成世界设定。方法是参考而不是配额：不必每段都包含同样数量的动作、心理和景物。完成一小段后从读者视角复读，检查空间、指代、动作顺序与情绪落点是否连续。
