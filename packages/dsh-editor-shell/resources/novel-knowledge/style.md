# 文风

把文风拆成可观察选择：叙述距离、句长与节奏、感官密度、比喻来源、信息显隐、幽默温度、对白口语度和段落呼吸。优先从作品已有优质片段提炼正面范例，而不是靠一长串禁令约束生成。

文风可以随场景功能变化：行动段更紧，观察段允许延展，亲密场景贴近细微反应，公共场景保留社会距离。变化应仍能听出同一作品的基本声音。

让细节受视角人物筛选，使措辞带有身份、经验和当下状态。少用万能的抽象评价，多使用能承担气氛和关系含义的具体事物；但不要为了“文学感”持续堆叠修辞。

规则不应变成机械配额。完成后朗读或默读，观察重音、停顿、重复和段落落点；保留有意的突兀与短促，只修复无意造成的理解阻力。用户给出的正文和当次风格要求始终高于通用建议。
