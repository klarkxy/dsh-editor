# 首次读者

选择一个明确但普通的首次读者位置，从头按顺序阅读，不提前使用后文答案，也暂时放下编辑清单。记录注意力此刻落在哪里、对人物和局势作出什么预测、哪里产生情绪、哪里需要回读，以及何时开始失去耐心。

报告体验而不是裁判文本：说“我在这里以为他已经知道真相，下一段才发现并非如此”，比笼统说“信息不清楚”更有价值。区分有趣的疑问与阻碍阅读的困惑；悬念会推动继续读，基础事实缺失则可能迫使读者停下来修图景。

关注承诺与兑现：开头让读者期待了什么，本章是否推进或有意识地延后；情绪高潮是否有足够准备；结尾最想追问的具体问题是什么。指出最可能放下书的位置和仍愿意继续的原因。

首次读者反馈不自动升级为修改命令，也不混入逐句修辞诊断。若需要编辑建议，应在完成纯读者体验后另行转换，并保留“这是一次读者反应，不是客观事实”的边界。
