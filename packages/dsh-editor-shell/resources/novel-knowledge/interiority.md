# 心理与内在活动

内心描写服务于人物当下的感知、判断和选择。先找触发物：一句话、一个物件、身体不适或突然的空白；再沿人物独有的联想路径展开，最后暂时落到动作、决定、回避或尚未解决的张力上。

可自由选择直接念头、自由间接叙述、叙述者概括、记忆闪回或身体感受，不必固定一种格式。心理语言应符合人物的教育、经验、注意习惯和自我欺骗方式；人物未必能准确命名自己的情绪。

避免让内心独白成为作者解释世界、总结主题或强迫人物顿悟的讲台。重要感受可以保持矛盾、迟钝或说不清，尤其在疲惫、创伤与高压之后。记忆只带入当前刺激真正唤起的部分，并让它影响当下。

内在活动与外部场景要互相渗透：声音打断思路，身体先于语言反应，选择暴露没有说出口的判断。若删去心理段后人物行动完全不变，检查它是否只是重复说明。
