# @klarkxy/dsh-recap

默认启用的回顾与检查点插件。

[English](../README.md)

需要 Node.js ≥22、DSH 0.1.5-rc.2，以及已加载的 @klarkxy/dsh-ai-services。Editor 已预装；独立 DSH 需要显式加载共享服务和此插件。

启用后，较长轮次结束或闲置返回会在后台生成回顾；聊天区不显示卡片、按钮、空状态或错误。已存回顾和手动生成入口统一放在「设置 → 回顾」。回顾不作为模型上下文。

Agent 检查点和语义检查点默认关闭，在「设置 → 回顾」中分别开启。检查点通过宿主的下一步入口加入上下文，保留任务约定和来源。

关闭插件会取消生成并停止注入，已存卡片与设置保留。当前宿主需要在客户端模块变化后重新加载界面；请先保存工作。
