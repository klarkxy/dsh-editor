# Canon 与项目事实

事实权威依次来自用户当次明确说明、项目中标记为正式或当前的设定与正文，以及能从这些材料直接推出的结论。草稿、旧版、备选方案和推测不能静默升级为 canon；来源冲突时保留冲突并请用户裁决。

检索时优先定位项目 Markdown 中的相关人物、时间、地点、物件和事件，再核对其状态。区分已生效、已替代、待确认和仅供构思的内容。人物视角所知不等于世界事实，叙述者判断也不必等于作者设定。

修改正文时检查稳定状态是否被改变：时间线、人物关系、伤势、持有物、知识边界、承诺与地理位置。若文本产生新的明确事实，应指出它可能需要同步到哪些项目资料，但只有用户要求时才生成同步提案。

不要建立隐藏数据库或自动状态机，也不要为了填满表格发明缺失项。必要时用来源路径说明依据；无法确认的内容明确标为未知、冲突或待定。任何同步都仍遵守可预览提案与用户确认边界。
