# 对白与多人场景

对白是人物采取行动的方式：索取、试探、拖延、遮掩、安抚、逼迫、结盟或保全面子。先判断每个人想让谈话向哪里移动、不能明说什么、手里有什么筹码；台词由这些压力生成，而不是轮流传递资料。

共享常识不必互相讲解。专业人物可以简短、含混或跳步，但读者仍需从动作、后果和少量必要信息理解局面。口语感来自省略、改口、抢话、答非所问和具体措辞，不等于大量语气词。

多人场景要维持所有在场者的存在。未发言者仍会观察、移动、交换眼神、被忽视或改变站位。用目标、节奏和关注点区分声音，避免每个人都使用同一套完整句式。

动作标签应帮助说明空间、时机或潜台词，不必给每句台词配动作。关键反应要落在正确的人身上，并让新信息或关系位移影响下一轮发言。结束时确认谈话实际改变了什么，而不只是把计划复述一遍。
