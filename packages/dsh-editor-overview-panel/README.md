# dsh-editor-overview-panel

桌面文档概览，默认开启，可在「设置 → 插件 → 文档概览」关闭。

用 `Ctrl+Shift+O` 或命令面板的「文档概览」打开中央浮层。查看文档数、总字数、各文档字数分布、近 30 日与近 12 周写作曲线；点击文档标题回到正文，列表可按标题或路径筛选，文档带有「纲」「态」标记表示已有大纲或状态。「最近编辑」区块列出最近修改的文档；目录较大时概览截断，并提示跳过的条目数量。

写作曲线来自保存时记录的写作日志，保存在作品目录的 `.dsh-editor/writing-log.json`，随作品文件夹移动。

新作品从 0 字建立基线，第一天保存的文字也计入净增。已有作品首次记录时以当时的总字数为基线，之后的增删按差值统计；不会把导入的旧稿算成当天新增。
